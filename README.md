# 量化交易入门 📈

一个面向零基础同学的中文量化交易学习站。用数据和代码理解市场，学会把一个交易想法变成可检验、可复现的策略。

## 📚 内容概览

- **第 1-8 章**：从量化交易定义到风险管理的完整学习路线
- **互动演示**：可视化均线交叉策略回测
- **术语表**：常用金融与量化概念速查

## ⚠️ 免责声明

本站内容仅用于学习交流，**不构成任何投资建议**。示例代码与数据均为教学用途，历史回测表现不代表未来收益。真实交易有亏损本金的风险。

## 📄 技术说明

纯静态站点（HTML/CSS/JS），使用：
- KaTeX：数学公式渲染
- Highlight.js：代码语法高亮
- Chart.js：图表展示

无需构建步骤，直接用浏览器打开 `index.html` 即可本地查看。
