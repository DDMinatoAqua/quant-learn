# Python Cookbook 第三版 · 中文网页阅读器

纯静态站点，可直接放到 GitHub Pages 的任意子路径（全部使用相对路径，运行时不访问外网）。

- 正文：开源翻译项目 [yidao620c/python3-cookbook](https://github.com/yidao620c/python3-cookbook)（熊能 及贡献者译），Apache License 2.0，见 `LICENSE-Apache-2.0.txt`。
- 原书：《Python Cookbook》3rd Edition，David Beazley & Brian K. Jones，O’Reilly Media，© 2013。
- 本站修改：rst → HTML 转换（docutils）、修正少量 rst 语法、译者照片改为本地文件、新增阅读器界面（app.js / style.css）。
- 代码高亮：highlight.js（BSD-3-Clause），位于 `vendor/hljs/`。
- 数据：书签/笔记/已读/阅读位置/主题/字号保存在浏览器 localStorage（`pcb-*`）。
