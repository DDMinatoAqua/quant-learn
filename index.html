第 1 章 · 什么是量化交易

用数学模型和计算机程序,基于数据做出(并执行)交易决策。

1.1 定义

量化交易(Quantitative Trading)是指把交易想法写成明确的规则(什么时候买、买多少、什么时候卖),再用历史数据检验这些规则,最后(可选)由程序自动执行的交易方式。核心特征是:

  • 规则化:决策逻辑可以写成代码,同样的输入一定得到同样的输出。
  • 可检验:可以在历史数据上回测,用统计指标评估好坏。
  • 系统化:减少情绪干扰(恐惧、贪婪、侥幸),严格执行纪律。

量化交易 vs. 主观交易

维度主观(discretionary)交易量化(systematic)交易
决策依据经验、直觉、新闻解读数据 + 预先定义的规则/模型
可复现性较难,同一个人不同时间判断也可能不同高,代码就是规则
覆盖范围精力有限,能盯的标的少可同时扫描成百上千个标的
主要风险情绪化、认知偏差模型失效、过拟合、数据错误、技术故障
常见相关概念:算法交易(Algorithmic Trading)多指用算法执行订单(如拆单减少冲击);高频交易(HFT)是持仓极短、依赖低延迟基础设施的一类量化交易。入门阶段我们关注的是中低频(日线级别)策略,个人电脑就能研究。

1.2 量化交易的完整工作流

① 想法 Idea→ ② 数据 Data→ ③ 策略 Strategy→ ④ 回测 Backtest→ ⑤ 风控 Risk→ ⑥ 实盘 Live
  1. 想法:来自观察、论文、书籍或经济逻辑。例如“趋势会延续一段时间”“价格偏离均值后倾向回归”。好的想法最好有可解释的原因(为什么这个规律会存在?谁在亏钱给你?)。
  2. 数据:获取并清洗所需数据(行情、财务、另类数据)。处理缺失值、复权、停牌、退市股票等问题。垃圾进,垃圾出。
  3. 策略:把想法翻译成精确的规则:入场信号、出场信号、仓位大小、调仓频率、交易标的池。
  4. 回测:在历史数据上模拟执行规则,计算收益、波动、夏普比率、最大回撤等。必须考虑交易成本,并警惕未来函数和过拟合(见第 6 章)。
  5. 风控:设定单笔/单日/总体亏损上限、仓位上限、分散化要求;思考策略在什么市场环境下会失效。
  6. 实盘:先模拟盘(paper trading),再小资金实盘,持续监控实盘与回测的偏差,定期复盘迭代。
这个流程是循环而不是直线:回测不理想就回到想法或数据;实盘偏离回测就要排查原因。大多数想法都会在回测阶段被淘汰,这很正常。

1.3 量化策略的常见类型

  • 趋势跟踪 / 动量:涨的继续涨、跌的继续跌(第 5 章均线交叉、动量)。
  • 均值回归:价格偏离“合理水平”后回归(布林带、配对交易)。
  • 多因子选股:用价值、质量、动量、规模等因子给股票打分并构建组合。
  • 套利:利用相关资产之间的定价偏差(期现套利、跨市场套利等),通常对执行速度和成本要求高。
  • 机器学习:用模型从大量特征中学习预测关系,强大但更容易过拟合。

1.4 一个现实的预期

量化不是“印钞机”。市场竞争激烈,公开、简单的策略往往收益有限甚至已经失效;回测漂亮的策略实盘亏损也很常见。学习量化最大的价值在于:用科学方法看待市场,学会区分“运气”和“真正的规律”。

第 2 章 · 金融市场与数据基础

量化的原材料是数据。先搞清楚数据长什么样、市场有什么规则。

2.1 OHLCV 与 K 线

最常见的行情数据是按时间周期(1 分钟、1 小时、1 天……)汇总的 OHLCV:

字段含义
Open 开盘价该周期第一笔成交价
High 最高价该周期内最高成交价
Low 最低价该周期内最低成交价
Close 收盘价该周期最后的成交价(A 股收盘价由集合竞价产生)
Volume 成交量该周期内的成交数量(股/手/张);成交额(Amount)是成交金额

K 线(蜡烛图)把一根 OHLC 画成一个“蜡烛”:实体表示开盘到收盘,上下影线表示最高、最低价。注意颜色习惯:A 股/港股通常“红涨绿跌”,美股/欧美软件通常“绿涨红跌”。

2.2 收益率

研究策略时,我们通常分析收益率而不是价格本身(不同价格的股票才可比较)。

简单收益率:

$$R_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1$$

对数收益率:

$$r_t = \ln\frac{P_t}{P_{t-1}} = \ln(1+R_t)$$
  • 对数收益率可以按时间直接相加:多期对数收益 = 各期之和;简单收益率需要连乘:\( 1+R_{0\to T} = \prod_t (1+R_t) \)。
  • 简单收益率可以按资产加权相加:组合收益 = \( \sum_i w_i R_i \)。
  • 收益率较小时两者近似相等:\( r \approx R \)。

复权

分红、送股、配股会让股价出现“跳空”,但持有者并没有真实亏损。回测必须使用复权价格:

  • 前复权:以最新价格为基准,向前调整历史价格。当前价格与行情软件一致,适合看图和回测(但历史价格会随新的除权事件变化)。
  • 后复权:以上市首日为基准向后调整,历史价格不变,当前价格可能远高于实际价格。

第 3 章 · 必备数学统计

不需要高深数学,但这几个概念必须吃透:它们是评价一切策略的语言。

3.1 均值与方差

设有 \(n\) 个收益率观测值 \(r_1,\dots,r_n\):

$$\bar r = \frac{1}{n}\sum_{i=1}^{n} r_i \qquad s^2 = \frac{1}{n-1}\sum_{i=1}^{n}(r_i-\bar r)^2 \qquad s=\sqrt{s^2}$$

均值衡量“平均赚多少”,标准差(波动率)衡量“收益有多不稳定”,是最常用的风险度量。样本方差除以 \(n-1\)(贝塞尔校正)以得到无偏估计,pandas 的 .std() 默认就是这样。

年化

若日收益近似独立同分布,一年约 252 个交易日(A 股约 240–245 天,常近似为 252 或 250):

$$\mu_{\text{年}} \approx 252\,\bar r_{\text{日}} \qquad \sigma_{\text{年}} \approx \sqrt{252}\;\sigma_{\text{日}}$$

波动率按 \(\sqrt{T}\) 缩放,因为独立随机变量之和的方差按 \(T\) 线性增长。

3.2 协方差与相关系数

$$\operatorname{Cov}(X,Y)=\frac{1}{n-1}\sum_{i}(x_i-\bar x)(y_i-\bar y) \qquad \rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{s_X\,s_Y}\in[-1,1]$$
  • \(\rho=1\):完全同向;\(\rho=-1\):完全反向;\(\rho=0\):没有线性关系(不代表独立)。
  • 两资产组合的方差:\( \sigma_p^2 = w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + 2w_1w_2\rho\,\sigma_1\sigma_2 \)。相关性越低,分散化降低风险的效果越好。
  • 相关性不是因果,而且在市场危机时资产间相关性往往会上升,分散化效果可能变差。

3.3 正态分布与“肥尾”

正态分布 \(N(\mu,\sigma^2)\) 的概率密度为:

$$f(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

约 68% 的概率落在 \(\mu\pm1\sigma\),约 95% 在 \(\mu\pm2\sigma\),约 99.7% 在 \(\mu\pm3\sigma\)。

真实资产收益通常呈现肥尾(fat tails)和偏度:极端涨跌出现的频率远高于正态分布的预测。用正态假设计算风险(如 VaR)可能严重低估暴跌风险。可以用峰度(kurtosis)和偏度(skewness)来检查:正态分布的超额峰度为 0。

3.4 夏普比率 Sharpe Ratio

衡量每承担一单位波动风险,获得多少超额收益:

$$\text{Sharpe} = \frac{E[R_p - R_f]}{\sigma(R_p - R_f)} \qquad \text{年化 Sharpe} \approx \sqrt{252}\times\frac{\overline{r_{\text{日}}-r_{f,\text{日}}}}{s_{\text{日}}}$$

其中 \(R_f\) 为无风险利率。夏普比率越高,风险调整后收益越好。注意:

  • 样本短时夏普的估计误差很大;同一策略换个时间段可能差别很大。
  • 它把上涨波动和下跌波动同等对待。只惩罚下行波动的版本叫 Sortino 比率。
  • 回测中尝试了很多参数后挑出的最高夏普会被高估(见第 6 章过拟合)。

3.5 最大回撤 Maximum Drawdown

设净值曲线为 \(V_t\),历史最高点 \(M_t = \max_{s\le t} V_s\):

$$\text{DD}_t = \frac{V_t - M_t}{M_t} \qquad \text{MDD} = \min_t \text{DD}_t$$

最大回撤表示“从最高点跌下来最多亏了多少”,直接反映持有策略时的心理痛苦和资金风险。还要关注回撤持续时间(多久才能回到前高)。Calmar 比率 = 年化收益 / |最大回撤|。

回本的不对称性:亏损 \(x\) 后需要上涨 \(\frac{x}{1-x}\) 才能回本。亏 20% 需涨 25%,亏 50% 需涨 100%。这就是为什么风控要优先控制回撤。

3.6 用代码计算这些指标

import numpy as np
import pandas as pd

def perf_stats(daily_ret: pd.Series, rf_annual: float = 0.0, periods: int = 252) -> dict:
    """根据日收益率序列计算常用绩效指标"""
    daily_ret = daily_ret.dropna()
    excess = daily_ret - rf_annual / periods
    equity = (1 + daily_ret).cumprod()                 # 净值曲线
    years = len(daily_ret) / periods
    cagr = equity.iloc[-1] ** (1 / years) - 1          # 年化复合收益
    vol = daily_ret.std() * np.sqrt(periods)           # 年化波动率
    sharpe = excess.mean() / excess.std() * np.sqrt(periods)
    drawdown = equity / equity.cummax() - 1
    return {
        "年化收益": cagr, "年化波动": vol, "夏普比率": sharpe,
        "最大回撤": drawdown.min(),
        "偏度": daily_ret.skew(), "超额峰度": daily_ret.kurt(),
    }

# 用随机生成的模拟数据测试(非真实行情)
rng = np.random.default_rng(42)
fake = pd.Series(rng.normal(0.0004, 0.01, 1000))
print(perf_stats(fake))

4.2 numpy 与 pandas 基础

import numpy as np
import pandas as pd

# 生成一段模拟价格(几何布朗运动),仅用于练习
rng = np.random.default_rng(0)
dates = pd.bdate_range("2020-01-01", periods=750)          # 工作日索引
daily_ret = rng.normal(loc=0.0003, scale=0.012, size=len(dates))
close = pd.Series(100 * np.exp(np.cumsum(daily_ret)), index=dates, name="close")

df = close.to_frame()
df["ret"] = df["close"].pct_change()                      # 简单收益率
df["log_ret"] = np.log(df["close"]).diff()                # 对数收益率
df["sma20"] = df["close"].rolling(20).mean()              # 20 日均线
df["vol20"] = df["ret"].rolling(20).std() * np.sqrt(252)  # 20 日年化波动率

print(df.describe())
monthly = df["close"].resample("ME").last()               # 重采样为月末价格(旧版 pandas 用 "M")
print(monthly.pct_change().head())
关键技巧:pct_change() 求收益率、rolling() 滚动窗口、shift() 错位(防止未来函数的关键!)、cumprod() 累乘得净值、resample() 改变频率。

4.4 backtrader:事件驱动回测

backtrader 按时间顺序逐根 K 线调用策略的 next(),下单默认在下一根 K 线开盘成交,天然避免了“用今天收盘价信号、按今天收盘价成交”的问题。

import backtrader as bt
import yfinance as yf

class SmaCross(bt.Strategy):
    params = dict(fast=10, slow=30)

    def __init__(self):
        fast = bt.ind.SMA(period=self.p.fast)
        slow = bt.ind.SMA(period=self.p.slow)
        self.crossover = bt.ind.CrossOver(fast, slow)   # 上穿 = 1,下穿 = -1

    def next(self):
        if not self.position:
            if self.crossover > 0:
                self.buy()
        elif self.crossover < 0:
            self.close()

df = yf.download("SPY", start="2015-01-01", end="2024-12-31",
                 auto_adjust=True, multi_level_index=False)

cerebro = bt.Cerebro()
cerebro.adddata(bt.feeds.PandasData(dataname=df))
cerebro.addstrategy(SmaCross)
cerebro.broker.setcash(100_000)
cerebro.broker.setcommission(commission=0.001)          # 0.1% 手续费
cerebro.addsizer(bt.sizers.PercentSizer, percents=95)  # 每次用 95% 资金
cerebro.addanalyzer(bt.analyzers.SharpeRatio, _name="sharpe", timeframe=bt.TimeFrame.Days, annualize=True)
cerebro.addanalyzer(bt.analyzers.DrawDown, _name="dd")

result = cerebro.run()[0]
print("期末资金:", round(cerebro.broker.getvalue(), 2))
print("夏普:", result.analyzers.sharpe.get_analysis())
print("最大回撤 %:", result.analyzers.dd.get_analysis().max.drawdown)

第 5 章 · 经典策略

以下策略都是教科书级的入门案例,目的是学习方法,而非可直接盈利的“圣杯”。

本章统一约定:close 为复权收盘价序列(pandas Series),信号在 t 日收盘后产生,t+1 日才持仓,所以收益计算都用 position.shift(1)。通用回测函数:

import numpy as np
import pandas as pd

def backtest(close: pd.Series, position: pd.Series, cost: float = 0.001) -> pd.Series:
    """position: t 日收盘后决定的目标仓位(0~1 或 -1~1)。返回策略日收益率。"""
    ret = close.pct_change().fillna(0)
    pos = position.shift(1).fillna(0)        # 关键:用昨天的信号赚今天的收益
    turnover = pos.diff().abs().fillna(0)    # 仓位变化量
    return pos * ret - turnover * cost       # 扣除交易成本

5.1 均线交叉(趋势跟踪)趋势

思路:短期均线代表近期趋势,长期均线代表长期趋势。短均线上穿长均线(“金叉”)视为上涨趋势开始,买入;下穿(“死叉”)卖出。

$$\text{SMA}_n(t) = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}$$

优点:规则简单,能抓住大趋势。缺点:信号滞后,震荡市中反复“打脸”,交易成本侵蚀收益。可以去 互动演示 亲手试试。

def sma_cross(close, fast=20, slow=60):
    sma_f = close.rolling(fast).mean()
    sma_s = close.rolling(slow).mean()
    return (sma_f > sma_s).astype(float)      # 1 = 持有, 0 = 空仓

strat_ret = backtest(close, sma_cross(close))
print("策略净值:", (1 + strat_ret).cumprod().iloc[-1])

5.2 动量策略 趋势

思路:过去一段时间表现好的资产,未来一段时间倾向于继续表现好。学术上有两类:

  • 时间序列动量:看资产自身过去收益的正负,正则做多、负则空仓/做空。
  • 横截面动量:在一篮子股票中买入过去收益最高的一组、卖出最低的一组。经典研究(Jegadeesh & Titman, 1993)常用过去 3–12 个月收益,且常跳过最近 1 个月(短期存在反转效应)。
# 时间序列动量:过去 120 个交易日收益为正则持有
def ts_momentum(close, lookback=120):
    past_ret = close / close.shift(lookback) - 1
    return (past_ret > 0).astype(float)

# 横截面动量:prices 为 DataFrame(列 = 股票),每月调仓,买入过去 12 个月(跳过最近 1 个月)收益最高的 20%
def xs_momentum_weights(prices: pd.DataFrame, top_q=0.2):
    monthly = prices.resample("ME").last()
    mom = monthly.shift(1) / monthly.shift(12) - 1       # 12-1 动量
    rank = mom.rank(axis=1, pct=True)
    w = (rank >= 1 - top_q).astype(float)
    w = w.div(w.sum(axis=1), axis=0).fillna(0)          # 等权
    return w   # 月末权重,下个月持有;应用到日频时需 shift 后前向填充
动量策略可能出现“动量崩溃”:市场急跌后的快速反弹中,动量组合可能在短时间内大幅亏损。

5.3 均值回归:布林带 反转

思路:价格围绕某个均值波动,偏离过大时倾向回归。布林带(Bollinger Bands)由均线和上下各 \(k\) 倍标准差组成:

$$\text{Mid}_t=\text{SMA}_n(t),\quad \text{Upper}_t=\text{Mid}_t+k\sigma_t,\quad \text{Lower}_t=\text{Mid}_t-k\sigma_t$$

常用参数 \(n=20, k=2\)。规则示例:收盘跌破下轨买入,回到中轨卖出。

def bollinger_mr(close, n=20, k=2.0):
    mid = close.rolling(n).mean()
    sd = close.rolling(n).std()
    lower = mid - k * sd
    # 入场 = 1,出场 = 0,其余时间保持上一状态(NaN 前向填充)
    signal = pd.Series(np.nan, index=close.index)
    signal[close < lower] = 1.0
    signal[close > mid] = 0.0
    return signal.ffill().fillna(0)

strat_ret = backtest(close, bollinger_mr(close))
均值回归的风险:趋势行情中价格可能一路突破下轨不回头(“接飞刀”)。通常需要止损或趋势过滤。趋势策略和均值回归策略往往在不同市场环境下表现好坏相反。

5.4 配对交易(统计套利)相对价值

思路:找到两只长期走势高度相关、且价差存在稳定关系(协整)的资产,如同行业的两只股票。当价差偏离历史均值时,做多“便宜”的一只、做空“贵”的一只,等待价差回归。

$$\text{spread}_t = \log P^A_t - \beta \log P^B_t \qquad z_t=\frac{\text{spread}_t-\mu_{\text{spread}}}{\sigma_{\text{spread}}}$$

规则示例:\(z_t>2\) 做空价差(空 A 多 B),\(z_t<-2\) 做多价差,\(|z_t|<0.5\) 平仓。

import statsmodels.api as sm
from statsmodels.tsa.stattools import coint

def pairs_signal(pa: pd.Series, pb: pd.Series, train_end: str, window=60, entry=2.0, exit_=0.5):
    la, lb = np.log(pa), np.log(pb)
    # 1) 仅用训练期数据做协整检验并估计对冲比例 beta(避免未来函数)
    tr_a, tr_b = la[:train_end], lb[:train_end]
    t_stat, p_value, _ = coint(tr_a, tr_b)
    print(f"协整检验 p 值: {p_value:.3f}")             # 通常要求 p < 0.05
    beta = sm.OLS(tr_a, sm.add_constant(tr_b)).fit().params.iloc[1]

    # 2) 计算价差的滚动 z-score
    spread = la - beta * lb
    z = (spread - spread.rolling(window).mean()) / spread.rolling(window).std()

    # 3) 生成价差仓位:+1 = 多 A 空 beta 份 B,-1 = 空 A 多 B
    pos = pd.Series(np.nan, index=z.index)
    pos[z > entry] = -1.0
    pos[z < -entry] = 1.0
    pos[z.abs() < exit_] = 0.0
    return pos.ffill().fillna(0), beta
要点:相关 ≠ 协整;协整关系可能因基本面变化而破裂(需要止损);A 股个人做空受限,配对交易在 A 股实践中较难,期货、加密货币市场更常见。

5.5 多因子模型入门 选股

思路:股票收益可以部分由一组共同“因子”解释。经典模型:

  • CAPM:只有市场因子 \(E[R_i]-R_f=\beta_i(E[R_m]-R_f)\)。
  • Fama-French 三因子(1993):市场、规模(SMB,小盘减大盘)、价值(HML,高账面市值比减低账面市值比)。
  • Carhart 四因子(1997):在三因子基础上加入动量因子;后续还有 Fama-French 五因子(2015,加入盈利能力与投资)。
$$R_{i,t}-R_{f,t}=\alpha_i+\beta_i\,\text{MKT}_t+s_i\,\text{SMB}_t+h_i\,\text{HML}_t+\varepsilon_{i,t}$$

实际选股中常见的做法是“打分法”:对每个因子做横截面标准化(z-score),加权合成综合得分,买入得分最高的一组股票,定期调仓。

# factors: MultiIndex DataFrame,index = (date, stock),列 = 因子值,如 pe、roe、mom_12_1
def zscore_cs(s: pd.Series) -> pd.Series:
    """横截面标准化,并对极端值缩尾到 ±3"""
    z = (s - s.mean()) / s.std()
    return z.clip(-3, 3)

def composite_score(factors: pd.DataFrame) -> pd.Series:
    z = factors.groupby(level="date").transform(zscore_cs)
    # 方向:PE 越低越好(取负),ROE、动量越高越好
    score = (-z["pe"] + z["roe"] + z["mom_12_1"]) / 3
    return score

# 每个调仓日选出得分前 10% 的股票等权持有
# top = score.groupby(level="date").apply(lambda s: s[s >= s.quantile(0.9)])
多因子研究的难点:因子数据必须按公告日对齐(否则未来函数)、股票池要包含退市股票、需要处理行业和市值中性化,还要检验因子是否只是数据挖掘的产物。

第 6 章 · 回测与常见陷阱

回测很容易“骗”自己。绝大多数回测好、实盘差的问题都来自以下几个陷阱。

6.1 未来函数(Look-ahead Bias)

在 t 时刻的决策中使用了 t 时刻还无法得知的信息。常见形式:

  • 用 t 日收盘价算出信号,又假设在 t 日收盘价成交并获得 t 日收益。
  • 财报数据按“报告期”而非“公告日”对齐(一季报 3 月 31 日截止,但可能 4 月底才公布)。
  • 用全样本的均值/标准差做标准化,或用全样本估计参数(如配对交易的 β)。
  • 使用了当天的最高价/最低价作为入场条件,却假设能以更优价格成交。
ret = close.pct_change()
signal = (close > close.rolling(20).mean()).astype(float)

wrong = signal * ret             # ❌ 今天收盘才知道的信号,却赚了今天的收益
right = signal.shift(1) * ret    # ✅ 昨天收盘的信号,今天持仓
print((1 + wrong).prod(), (1 + right).prod())   # wrong 往往好得离谱
一个经验法则:如果回测结果好得令人难以置信(比如夏普远高于业内顶尖水平、几乎没有回撤),先假设代码有 bug,尤其是未来函数。

6.2 过拟合(Overfitting)与数据窥探

参数和规则调得太多,策略记住了历史噪声而非真实规律。在 100 组参数里挑出最好的那组,其历史表现几乎必然被高估。

应对方法:

  • 样本内/样本外划分:在训练集上开发,在从未看过的测试集上只验证一次。
  • 滚动前向分析(Walk-forward):滚动地“训练一段 → 测试下一段”,更接近真实使用方式。
  • 参数稳健性:好的策略在参数附近一片区域都表现不错,而不是只在某个“尖峰”参数有效。
  • 控制尝试次数:记录你试过的所有想法;Bailey 与 López de Prado 提出的紧缩夏普比率(Deflated Sharpe Ratio)可以对多重检验进行校正。
  • 规则要少、要有逻辑:能用经济逻辑解释的规律更可能持续。
# 简单的样本内 / 样本外划分
in_sample = close[:"2019-12-31"]
out_sample = close["2020-01-01":]

best = max(((f, s) for f in range(5, 50, 5) for s in range(20, 200, 10) if f < s),
           key=lambda p: backtest(in_sample, sma_cross(in_sample, *p)).mean())
print("样本内最佳参数:", best)
oos = backtest(out_sample, sma_cross(out_sample, *best))   # 只看一次!

6.3 幸存者偏差(Survivorship Bias)

只用现在还存在的股票做回测,忽略了历史上已退市、被并购、破产的公司。这些“死掉”的公司往往表现很差,剔除它们会让策略(尤其是买入小盘股、低价股、困境股的策略)看起来更好。

应对:使用包含退市股票的历史时点股票池(point-in-time universe);指数成分股也要用当时的成分,而不是今天的成分。

6.4 交易成本与滑点

  • 显性成本:佣金、印花税(A 股卖出)、过户费、交易所费用。
  • 买卖价差:市价买入付卖一价、卖出得买一价。
  • 滑点(Slippage):实际成交价与预期价格的差异,来自价格波动和延迟。
  • 市场冲击(Market Impact):自己的大单推动价格向不利方向移动,资金量越大越明显。

换手越高的策略,成本影响越大。粗略估算:若每次换仓双边成本 0.2%,一年换仓 100 次,仅成本就约侵蚀 20% 的收益。务必在回测中加入保守的成本假设,并测试成本加倍后策略是否依然成立。

6.5 其他需要注意的问题

  • A 股特殊规则:涨停时往往买不进、跌停时往往卖不出;T+1;停牌期间无法交易。回测要识别这些情况。
  • 流动性:小盘股成交量小,回测中的仓位在现实中可能根本买不到。
  • 样本区间偏差:只在牛市回测的趋势策略、只在震荡市回测的反转策略都会误导你。
  • 市场机制变化(Regime change):规则、参与者结构、波动率水平都会变化,历史规律可能消失。
回测自查清单 ✅
  1. 信号是否全部只用到了当时可得的数据?(shift 了吗?财报用公告日了吗?)
  2. 股票池是否包含退市股?
  3. 是否计入了佣金、税费、滑点?成本翻倍后结果如何?
  4. 是否在样本外数据上验证过?参数附近是否稳健?
  5. 最大回撤和回撤时长我能承受吗?
  6. 策略为什么能赚钱?对手方是谁?

第 7 章 · 风险管理与仓位

“先求不败,再求胜。” 决定你能在市场里活多久的,往往是仓位和风控,而不是入场信号。

7.1 止损

  • 固定比例止损:从入场价下跌 \(x\%\) 即离场。
  • 移动止损(Trailing Stop):从持仓期间最高价回落 \(x\%\) 离场,让利润奔跑。
  • 波动率止损:基于 ATR(平均真实波幅)设定止损距离,如入场价 − 2×ATR,能适应不同标的的波动水平。
  • 时间止损:持有一定时间仍未达到预期即离场。
$$\text{TR}_t=\max\big(H_t-L_t,\;|H_t-C_{t-1}|,\;|L_t-C_{t-1}|\big) \qquad \text{ATR}_t=\text{TR 的 } n \text{ 日平均(常用 } n=14)$$ 
def atr(df: pd.DataFrame, n: int = 14) -> pd.Series:
    prev_close = df["Close"].shift(1)
    tr = pd.concat([df["High"] - df["Low"],
                    (df["High"] - prev_close).abs(),
                    (df["Low"] - prev_close).abs()], axis=1).max(axis=1)
    return tr.rolling(n).mean()     # 简单平均;Wilder 原始定义使用指数平滑
止损并非免费:在跳空(如 A 股跌停、隔夜大幅低开)时,实际成交价可能远差于止损价;止损过紧会被正常波动频繁触发。止损规则也应放进回测里检验。

7.2 仓位管理

固定风险比例法

每笔交易最多亏损账户的固定比例(业内常见的经验值是 1%–2%):

$$\text{仓位股数}=\frac{\text{账户权益}\times\text{单笔风险比例}}{\text{入场价}-\text{止损价}}$$

例:账户 10 万元,单笔风险 1% = 1000 元,入场价 50 元,止损价 45 元,则最多买 \(1000/5=200\) 股(A 股需按 100 股取整)。

波动率目标(Volatility Targeting)

根据资产近期波动率调整仓位,让组合波动保持在目标水平附近:

$$w_t=\frac{\sigma_{\text{目标}}}{\hat\sigma_t}\quad(\text{通常设置上限,如 } w_t\le 1 \text{ 或杠杆上限})$$ 
def vol_target_weight(close, target_vol=0.15, lookback=20, max_w=1.0):
    realized = close.pct_change().rolling(lookback).std() * np.sqrt(252)
    return (target_vol / realized).clip(upper=max_w)   # 波动越大,仓位越小

7.3 凯利公式(Kelly Criterion)

凯利公式给出使长期资金对数增长率最大的下注比例。

离散形式(胜率 \(p\),败率 \(q=1-p\),赔率 \(b\) = 盈利额 / 亏损额):

$$f^*=p-\frac{q}{b}=\frac{bp-q}{b}$$

例:胜率 55%,盈亏比 1:1,则 \(f^*=0.55-0.45=0.10\),即每次下注 10% 的资金。

连续形式(策略超额收益均值 \(\mu\)、波动率 \(\sigma\),近似假设收益正态):

$$f^*=\frac{\mu - r_f}{\sigma^2}$$
实践中几乎没人用“全凯利”。原因:(1) \(p\)、\(\mu\)、\(\sigma\) 都是估计值,误差很大,高估会导致过度下注;(2) 全凯利的净值波动和回撤非常剧烈。常见做法是使用半凯利或更低比例,把它当作仓位的上限参考。超过凯利比例下注,长期增长率反而下降,甚至趋向破产。

7.4 组合层面的风险控制

  • 分散化:跨标的、跨策略、跨市场,关注相关性(尤其是危机时的相关性)。
  • 集中度上限:单一标的、单一行业的最大权重。
  • 杠杆控制:杠杆放大收益也放大亏损,还可能触发强制平仓。
  • 回撤熔断:组合回撤达到阈值时降低仓位或暂停策略,复盘原因。
  • 操作风险:代码 bug、数据错误、网络中断、下错单。实盘系统需要日志、告警和人工复核。

一条从零到能独立完成策略研究的路线,以及值得一读的经典书籍。

8.1 学习路线图

阶段 0 · 打基础(约 1–2 个月)
  • Python 基础 + numpy / pandas / matplotlib
  • 概率统计:均值方差、分布、回归、假设检验
  • 金融基础:股票、指数、ETF、期货的交易规则,收益率与复权
阶段 1 · 第一个回测(约 1 个月)
  • 用 AkShare / yfinance 下载数据,纯 pandas 实现均线交叉回测
  • 正确计算夏普、最大回撤,加入交易成本
  • 再用 backtrader 或 vectorbt 复现,对比结果
阶段 2 · 策略与方法论(约 2–3 个月)
  • 实现第 5 章所有策略,做样本内/样本外与参数稳健性分析
  • 学习多因子:因子构建、IC 分析、分组回测、中性化
  • 阅读经典书籍和论文,复现一篇论文结论
阶段 3 · 进阶与实践(持续)
  • 组合优化与风险模型、机器学习在量化中的应用(注意过拟合)
  • 模拟盘跟踪,记录实盘与回测的偏差
  • 若考虑真实资金:先非常小规模,充分了解合规要求与风险

8.3 平台、文档与开源项目

  • 开源项目:Microsoft Qlib(AI 量化研究平台)、zipline、alphalens(因子分析)、Quantopian 讲义存档

8.4 给初学者的建议

  1. 先求正确,再求盈利:一个没有未来函数、计入成本的平庸回测,比一个有 bug 的漂亮回测有价值得多。
  2. 保持研究日志:记录每个想法、参数和结果,包括失败的。
  3. 从简单开始:先把均线策略做“对”,再尝试复杂模型。
  4. 对“稳赚”“高胜率”的宣传保持警惕,尤其是收费荐股、带单。
