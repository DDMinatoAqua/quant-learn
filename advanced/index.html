B. 新工具 1:向量和矩阵的写法

为什么需要

入门站只处理一两个资产。一旦资产变成 50 个、500 个,逐个写公式就写不下了。线性代数的写法只是一种“批量记账”的简写,背后的运算你都会。

符号

符号含义例子(3 个资产)
\(w\)权重向量:一列数,第 \(i\) 个是资产 \(i\) 的仓位占比\(w=(0.5,\,0.3,\,0.2)^\top\)
\(\mu\)预期收益向量\(\mu=(8\%,\,6\%,\,3\%)^\top\)
\(^\top\)转置:把列变成行(或反过来)\(w^\top\) 是一行数
\(w^\top\mu\)内积:对应位置相乘再相加\(0.5\times8\%+0.3\times6\%+0.2\times3\%=6.4\%\)
\(\Sigma\)协方差矩阵:第 \(i\) 行第 \(j\) 列是 \(\operatorname{Cov}(r_i,r_j)=\rho_{ij}\sigma_i\sigma_j\);对角线是各自的方差 \(\sigma_i^2\)3×3 的对称表格
\(w^\top\Sigma w\)组合方差 \(=\sum_i\sum_j w_i w_j \Sigma_{ij}\)见下面的手算
\(\Sigma^{-1}\)逆矩阵:满足 \(\Sigma^{-1}\Sigma=I\)(单位矩阵);相当于矩阵版的“除法”代码里用 np.linalg.solve 而不是显式求逆
\(\mathbf 1\)全是 1 的向量;\(\mathbf 1^\top w=\sum_i w_i\)“满仓”约束写成 \(\mathbf 1^\top w=1\)
手算例子:两资产组合的方差。资产 1 波动 \(\sigma_1=20\%\),资产 2 波动 \(\sigma_2=10\%\),相关系数 \(\rho=0.3\),权重 \(w=(0.6,0.4)\)。
  1. 协方差 \(\Sigma_{12}=\rho\sigma_1\sigma_2=0.3\times0.2\times0.1=0.006\);方差 \(\Sigma_{11}=0.04\),\(\Sigma_{22}=0.01\)。
  2. \(w^\top\Sigma w = w_1^2\Sigma_{11}+w_2^2\Sigma_{22}+2w_1w_2\Sigma_{12} = 0.36\times0.04+0.16\times0.01+2\times0.24\times0.006=0.0144+0.0016+0.00288=0.01888\)。
  3. 组合波动 \(=\sqrt{0.01888}\approx 13.7\%\),低于加权平均波动 \(0.6\times20\%+0.4\times10\%=16\%\)——这多出来的 2.3 个百分点就是分散化的好处,来源于 \(\rho<1\)。
import numpy as np
w = np.array([0.6, 0.4])
sigma = np.array([0.20, 0.10])
corr = np.array([[1.0, 0.3], [0.3, 1.0]])
Sigma = np.outer(sigma, sigma) * corr   # 协方差矩阵 = σ_i σ_j ρ_ij
print(w @ Sigma @ w)                    # 0.01888  —— @ 就是矩阵乘法
print(np.sqrt(w @ Sigma @ w))           # 0.1374...

C. 新工具 2:线性回归(最小二乘)

直觉

回归就是“用一条直线(或一个平面)去解释一个变量”。在量化里它无处不在:算贝塔、做因子中性化(第 2 章)、估计对冲比率(第 3 章)、做收益归因(第 7 章)。

公式

有 \(n\) 个样本,因变量 \(y\)(长度 \(n\) 的向量),自变量矩阵 \(X\)(\(n\) 行 \(k\) 列,每列一个解释变量,通常含一列全 1 作为截距)。模型 \(y = X\beta + \varepsilon\),其中 \(\beta\) 是要估计的 \(k\) 个系数,\(\varepsilon\) 是残差。普通最小二乘 (Ordinary Least Squares, OLS) 选择让残差平方和 \(\sum_i \varepsilon_i^2\) 最小的 \(\beta\),解是

$$\hat\beta = (X^\top X)^{-1}X^\top y .$$

残差 \(\hat\varepsilon = y - X\hat\beta\) 有一个重要性质:它与 \(X\) 的每一列都不相关。第 2 章的“中性化”正是利用这一点——把因子对行业、市值回归,残差就是“去掉了行业和市值影响”的部分。

手算例子:\(x=(1,2,3)\),\(y=(2,4,5)\),只估计斜率(无截距)。\(\hat\beta = \frac{\sum x_iy_i}{\sum x_i^2}=\frac{2+8+15}{1+4+9}=\frac{25}{14}\approx1.786\)。残差 \(=(2-1.786,\;4-3.571,\;5-5.357)=(0.214,\,0.429,\,-0.357)\),检查 \(\sum x_i\hat\varepsilon_i=0.214+0.857-1.071=0\) ✔。

D. 新工具 3:假设检验、p 值与 t 值

研究中我们反复问:“这个效果是真的,还是运气?” 统计检验给出一种标准化的回答方式:

  1. 先假设原假设 (null hypothesis, H₀):没有效果,例如“策略的真实平均收益 = 0”。
  2. 计算一个统计量,例如 t 值 (t-statistic):\(t=\dfrac{\bar x}{s/\sqrt n}\),其中 \(\bar x\) 是样本均值,\(s\) 是样本标准差,\(n\) 是样本数。分母 \(s/\sqrt n\) 叫标准误,衡量“样本均值本身有多不确定”。
  3. p 值 (p-value):如果 H₀ 为真,看到至少这么极端结果的概率。p 值小(常用阈值 0.05)说明“纯靠运气很难出现”,于是拒绝 H₀。
例子:某策略 36 个月的月收益均值 \(\bar x = 0.8\%\),标准差 \(s=4\%\)。标准误 \(=4\%/\sqrt{36}=0.667\%\),\(t=0.8/0.667=1.2\)。在正态近似下双侧 p 值约 0.23——不能说这个策略显著赚钱。注意这和夏普的关系:月夏普 \(=0.8/4=0.2\),\(t = \text{夏普}\times\sqrt n\)。
两个最常见的误解:① p 值不是“策略无效的概率”;② p<0.05 只在“只检验了一次”时才有它字面的含义。如果你试了 100 个策略只报告最好的那个,p 值就失真了——这是第 7 章“多重检验”的主题。

直觉

1.2 复权:从原理到手算

直觉

假设你持有 1 股价格 20.4 元的股票。公司宣布“每股派现 0.4 元、每 1 股送 1 股”。除权除息日开盘后,你手里变成了 2 股和 0.4 元现金,而股价会被交易所调整到大约 10 元。你的财富几乎没变(2 × 10 + 0.4 = 20.4),但行情软件上的价格从 20.4“跌”到了 10。如果回测直接用这条原始价格,就会以为发生了 −51% 的暴跌。复权 (price adjustment) 就是把这种“账面上的跳空”抹平,让价格序列只反映真实的涨跌。

数学:除权参考价与复权因子

交易所会在除权除息日公布一个除权(息)参考价 (ex-rights reference price),作为当天涨跌幅计算的基准。不考虑配股时:

$$P^{\text{ref}}_t=\frac{P^{\text{close}}_{t-1}-D}{1+S}$$
符号含义
\(P^{\text{close}}_{t-1}\)除权日前一个交易日的收盘价
\(D\)每股现金分红(税前,元)
\(S\)每股送转股数(“10 送 10”即 \(S=1\),“10 转 5”即 \(S=0.5\))

(有配股时,分子再加上“配股价 × 每股配股比例”,分母再加上“每股配股比例”,以交易所公式为准。)

当天的单日复权因子定义为“前收盘 ÷ 参考价”,其余日子为 1;把它从第一天起连乘,得到累计复权因子 (cumulative adjustment factor) \(F_t\):

$$f_t=\frac{P^{\text{close}}_{t-1}}{P^{\text{ref}}_t}\ (\text{除权日}),\qquad F_t=\prod_{s\le t} f_s .$$

于是有两种复权价:

  • 后复权 (backward-adjusted, 以起点为基准):\(P^{\text{hfq}}_t = P_t \times F_t\)。最早那天的价格不变,之后的价格被“放大”。
  • 前复权 (forward-adjusted, 以最新价为基准):\(P^{\text{qfq}}_t = P_t \times F_t / F_T\),\(T\) 是最后一天。最新价格和行情软件一致,历史价格被“缩小”。
为什么两种复权算出的收益率完全相同?因为 \(P^{\text{qfq}}_t\) 只是 \(P^{\text{hfq}}_t\) 除以一个常数 \(F_T\)。收益率是比值 \(P_t/P_{t-1}\),常数会被约掉。所以算收益用哪种都行;区别在于“价格水平”:
  • 前复权的历史价格会随着每次新的分红而改变(因为 \(F_T\) 变了)。如果你的策略用到价格水平(例如“股价低于 5 元”过滤),前复权会引入前视偏差——过去某天的“前复权价”包含了未来分红的信息。
  • 后复权价格水平和当时的真实价格不一致,所以“股价门槛”“涨跌停价”“下单股数”必须用不复权的原始价格计算。
  • 实践规则:收益和技术指标用复权价;与真实价格水平相关的规则(涨跌停、一手 100 股、价格过滤)用原始价。
手算例子(和下面的代码同一组数):前收盘 20.4 元,派现 0.4 元,10 送 10。
  1. 参考价 \(=(20.4-0.4)/(1+1)=10.0\) 元。
  2. 单日因子 \(f=20.4/10.0=2.04\);之前因子为 1,所以除权日起累计因子 \(F=2.04\)。
  3. 除权日收盘 10.0 元 → 后复权价 \(10.0\times2.04=20.4\),与前一天相同,真实收益 0%;而原始价格的“收益” \(=10/20.4-1=-50.98\%\)。
  4. 第一天 20.0 元的前复权价 \(=20.0\times1/2.04\approx9.804\) 元。

import pandas as pd

# 一只虚构股票的 6 个交易日原始(不复权)收盘价 —— 教学用模拟数据
raw = pd.DataFrame({
    "date": pd.to_datetime(["2024-06-03", "2024-06-04", "2024-06-05",
                            "2024-06-06", "2024-06-07", "2024-06-11"]),
    "close": [20.0, 20.4, 10.0, 10.3, 10.1, 10.5],
})
# 公司行为(corporate action)表:6 月 5 日除权除息,每股派现 0.4 元,每 1 股送转 1 股
actions = pd.DataFrame({
    "date": pd.to_datetime(["2024-06-05"]),
    "cash_div": [0.4],     # 每股现金分红(元)
    "split": [1.0],        # 每股送转股数:10 送 10 即每股送 1 股
})

df = raw.merge(actions, on="date", how="left").fillna({"cash_div": 0.0, "split": 0.0})
df["prev_close"] = df["close"].shift(1)                       # 前一交易日收盘价
# 除权参考价 = (前收盘 − 每股派现) / (1 + 每股送转)
df["ref_price"] = (df["prev_close"] - df["cash_div"]) / (1 + df["split"])
# 单日复权因子:除权日 = 前收盘 / 除权参考价,其它日子 = 1
df["step"] = (df["prev_close"] / df["ref_price"]).where(df["cash_div"] + df["split"] > 0, 1.0)
df["adj_factor"] = df["step"].cumprod()                        # 累计复权因子(从第一天起连乘)
df["hfq"] = df["close"] * df["adj_factor"]                     # 后复权价:第一天价格不变
df["qfq"] = df["hfq"] / df["adj_factor"].iloc[-1]              # 前复权价:最后一天价格不变

df["ret_raw"] = df["close"].pct_change()                       # 用原始价算的“收益”(错的)
df["ret_adj"] = df["hfq"].pct_change()                         # 用复权价算的收益(对的)
pd.set_option("display.width", 120)
df["date"] = df["date"].dt.strftime("%m-%d")                     # 只显示月-日,便于阅读
print(df[["date", "close", "ref_price", "adj_factor", "hfq", "qfq", "ret_raw", "ret_adj"]].round(4).to_string(index=False))

1.3 停牌、涨跌停与可交易性

直觉

回测最常见的“作弊”之一是买到了现实中买不到的东西。A 股有涨跌停 (price limit)制度:价格触及涨停后,卖方很少,排队买入的单子往往成交不了;触及跌停后,想卖的人排长队。停牌 (trading suspension)期间则完全不能交易。如果你的策略恰好喜欢“强势股”,而回测假设在涨停价都能买到,收益会被严重高估。

规则(示意,以交易所最新规定为准)

  • 主板普通股票日涨跌幅限制一般为 ±10%,风险警示(ST)股票为 ±5%;创业板、科创板为 ±20%;北交所为 ±30%。新股上市初期等情形另有规定。
  • 涨停价 = 前收盘 × (1 + 限制比例),按交易所规则四舍五入到 0.01 元。
  • “一字涨停”:开盘即涨停且全天不打开(最低价 = 涨停价),通常意味着几乎买不到。

回测中的保守规则

我们没法知道排队能不能轮到自己,所以采用保守假设:

情形买入卖出
停牌(成交量为 0)❌❌(只能继续持有,并按停牌前价格估值)
一字涨停❌✅
按收盘价成交且收盘跌停✅❌
盘中触及涨停但打开过取决于你的成交价假设;按开盘价成交时只需检查开盘价是否在涨跌停价上

bar["can_buy"] = ~bar["suspended"] & ~bar["one_word_up"]              # 停牌、一字涨停都买不进
bar["can_sell"] = ~bar["suspended"] & ~bar["close_at_down"]           # 停牌、跌停(按收盘价成交时)卖不出
print(bar[["code", "board", "pre_close", "close", "up_limit", "down_limit",
           "suspended", "one_word_up", "can_buy", "can_sell"]].to_string(index=False))

1.4 Point-in-time 数据与历史股票池

直觉

Point-in-time(时点一致)(point-in-time, PIT)数据的意思是:对任意历史时刻 \(t\),数据库能回答“在 \(t\) 时刻,我们能看到的数据是什么样子”。 这比听上去难,因为:

  1. 财报有延迟:2023 年年报的报告期是 2023-12-31,但可能 2024 年 4 月才公布。在 2024 年 3 月,你还看不到它。
  2. 数据会被修订:公司可能发布更正公告;数据商可能修正录入错误。今天的数据库里通常只保留“最终版”,丢掉了“当时看到的版本”。
  3. 股票池会变化:今天的指数成分股列表里没有那些已经退市、被调出的股票。用它回测过去就是幸存者偏差 (survivorship bias)。

数学化的定义

把每条记录看作三元组 \((\text{实体}, \text{报告期 } p, \text{公告时间 } a)\) 加数值 \(v\)。在决策时刻 \(t\),可用的信息集是

$$\mathcal I_t = \{(p, a, v) : a \le t\}$$

“最新一期财报”= 在 \(\mathcal I_t\) 里报告期 \(p\) 最大的那一期;如果同一报告期有多次公告(原版、更正版),取 \(a\) 最大的那一条。关键点:过滤条件用的是公告时间 \(a\),不是报告期 \(p\)。

例子:某公司 2023 年报(净利润 10.0)于 2024-04-20 公布,2024-06-15 更正为 8.5;2024 年一季报(3.0)于 2024-04-28 公布。
  • 2024-03-29 调仓:\(\mathcal I_t\) 为空 → 没有年报可用(而按报告期对齐会错误地“看到”年报)。
  • 2024-04-30 调仓:能看到年报原版(10.0)和一季报(3.0);最新一期是一季报。如果你的因子要用“2023 年报净利润”,应取 10.0 而不是更正后的 8.5。
  • 2024-06-28 调仓:2023 年报净利润已更正为 8.5。

import pandas as pd

# 财报表:报告期(period)和真实公告日(ann_date)不是一回事 —— 教学用虚构数据
fin = pd.DataFrame({
    "code": ["A", "A", "A", "A"],
    "period": pd.to_datetime(["2023-12-31", "2024-03-31", "2023-12-31", "2024-06-30"]),
    "ann_date": pd.to_datetime(["2024-04-20", "2024-04-28", "2024-06-15", "2024-08-25"]),
    "net_profit": [10.0, 3.0, 8.5, 6.2],   # 第三行:2023 年报在 6 月 15 日被“更正”为 8.5
})
# 每月末调仓一次,想知道“当时”能看到的最新一期净利润
rebal = pd.to_datetime(["2024-03-29", "2024-04-30", "2024-06-28", "2024-08-30"])

# ❌ 错误做法 1:按报告期对齐 —— 3 月 29 日就“看到了”4 月 20 日才公布、甚至 6 月才更正的数据
wrong = pd.merge_asof(pd.DataFrame({"code": "A", "date": rebal}),
                      fin.sort_values("period"), left_on="date", right_on="period", by="code")

def pit_latest(fin, code, asof):
    """point-in-time 查询:只用 asof 当天及以前已公告的记录,
    取其中报告期最新的一期;同一报告期有多次公告时取最后一次(更正版)。"""
    known = fin[(fin["code"] == code) & (fin["ann_date"] <= asof)]     # 1) 只保留当时已知的
    if known.empty:
        return None                                                    # 当时还没有任何财报
    known = known.sort_values(["period", "ann_date"])                  # 2) 按报告期、公告日排序
    return known.iloc[-1]                                              # 3) 最后一行 = 最新期的最新版本

# ❌ 错误做法 2:用“今天的数据库快照”——每个报告期只保留最终修订版,丢失了更正前的数值
snapshot_fy23 = fin[fin["period"] == "2023-12-31"].sort_values("ann_date").iloc[-1]["net_profit"]

rows = []
for d in rebal:
    r = pit_latest(fin, "A", d)
    fy23 = fin[(fin["period"] == "2023-12-31") & (fin["ann_date"] <= d)].sort_values("ann_date")
    rows.append({"date": d.date(),
                 "wrong_by_period": wrong.loc[wrong["date"] == d, "net_profit"].item(),
                 "pit_period": None if r is None else r["period"].date(),
                 "pit_profit": None if r is None else r["net_profit"],
                 "fy23_snapshot": snapshot_fy23,                                   # 错:永远是 8.5
                 "fy23_pit": fy23["net_profit"].iloc[-1] if len(fy23) else None})  # 对:10.0 → 8.5
print(pd.DataFrame(rows).to_string(index=False))

历史股票池

同样的逻辑适用于股票池:回测某天的“沪深 300 成分股”,必须用那一天的成分股名单(包括后来被调出、退市的股票),而不是今天的名单。实践中需要一张 (指数, 股票, 纳入日, 剔除日) 的历史成分表,以及一张包含已退市股票的完整行情表。退市股票往往在退市前大跌,把它们漏掉会让“买入低价股”“买入困境股”一类策略看起来特别好。

每接入一个新数据源,建议逐项检查(可以写成自动化的数据质量测试):

检查项怎么查常见处理
主键重复df.duplicated(["date","code"]).sum()弄清原因(数据修订?合并错误?)后去重
缺失值按日期、按股票统计缺失比例价格:停牌用前值并标记;财务:不要用 0 填充,保留缺失并在因子计算时剔除
逻辑约束low ≤ open, close ≤ high;成交量 ≥ 0违反的行要追查,通常是数据错误

极端值收益率超出涨跌幅限制(除权日、新股除外)大多是未复权或数据错误
交易日历和交易所日历对比不要用自然日或工作日代替交易日
时区与时间戳分钟数据的时间戳是区间开始还是结束?统一约定并写进文档——差一根 K 线就可能是未来函数
缺失值填充的一个陷阱:bfill()(向后填充,旧版 pandas 写作 fillna(method="bfill"))会用未来的值填过去的缺失,是隐蔽的未来函数。在时间序列里只应使用前值填充 ffill(),而且要想清楚“前值”在当时是否已知。

1.6 存储:Parquet 与本地数据库

直觉

CSV 是“一行一行”存的文本,读一列也得把整行都解析一遍。Parquet (Apache Parquet) 是列式存储 (columnar storage)格式:同一列的数据连续存放并压缩,读取时可以只读需要的列;再配合按年份、按日期的分区 (partitioning),还可以跳过不需要的文件。对“几千只股票 × 十几年 × 几十个字段”的面板数据,这能把读取时间从分钟级降到秒级。

1.8 常见错误

  • ❌ 用前复权价格做“价格水平”相关的判断(低价股过滤、整手计算)→ 引入未来信息。✅ 价格水平用原始价,收益用复权价。
  • ❌ 假设涨停也能买到、跌停也能卖出 → 动量、打板类策略收益被高估。✅ 用保守的可交易性规则,并统计“因不可交易被拒绝的订单比例”。
  • ❌ 财报按报告期对齐;使用只保存最终版的数据库 → 前视偏差。✅ 按公告日做 point-in-time 查询,保留修订历史。
  • ❌ 用今天的成分股回测过去;行情表里没有退市股票 → 幸存者偏差。✅ 使用历史成分表和包含退市股票的全量数据。
  • ❌ 用 bfill 填充缺失、用 0 填充财务缺失 → 未来函数 / 虚假的极端值。
  • ❌ 在 notebook 里手动改数据 → 结果不可复现。✅ 原始数据只读,所有变换都由脚本完成。

2.1 因子研究在做什么:截面视角

直觉

入门站的均线策略问的是“这只股票明天涨还是跌”——这是时间序列 (time-series)问题。因子研究问的是另一个问题:“在同一天的这 500 只股票里,哪些会比其它的涨得多?”——这是截面 (cross-section)问题。截面问题有两个好处:

  • 大盘整体涨跌(最难预测的部分)在“相对比较”中被抵消了;
  • 每一期都有几百个样本,统计上比单只股票的一条时间序列有力得多。

因子 (factor)在这里指:对每只股票、每个时点计算出的一个数字 \(f_{i,t}\),我们猜测它和该股票下一期收益 \(r_{i,t+1}\) 的截面排序有关。

一条完整的流水线

原始数据(PIT)→因子构造→去极值→标准化→中性化→IC / 分层检验→衰减与换手→多因子合成

2.2 因子构造:从想法到公式

好的因子背后应该有一个能讲清楚的理由:是风险补偿(承担了别人不愿承担的风险)?是行为偏差(投资者系统性地反应过度或不足)?还是结构性约束(某些机构不能买某类股票)?下面是几类经典因子的常见构造方法(具体定义在文献和业界有很多变体):

类别例子常见构造数据时点注意
动量12-1 动量过去 12 个月累计收益,但跳过最近 1 个月(因为最近 1 个月常呈短期反转)用复权价
反转短期反转过去 1 个月(或 1 周)收益取负号用复权价
价值盈利收益率 EP最近 12 个月净利润 ÷ 总市值(PE 的倒数,避免 PE 在亏损时的符号问题)净利润按公告日 PIT
质量ROE净利润 ÷ 净资产财报 PIT
低风险低波动过去 N 日收益波动率取负号—
规模小市值对数总市值取负号股本要用当时的股本
流动性换手率过去 N 日平均换手率—
约定:我们总是把因子的方向调整成“值越大,预期收益越高”,这样后面的检验和合成都统一。例如低波动因子 = −波动率。

以 12-1 动量为例,写成公式:\(\text{MOM}_{i,t}=\dfrac{P_{i,t-21}}{P_{i,t-252}}-1\),\(P\) 是复权价,\(t\) 以交易日计。用 pandas:mom = close.shift(21) / close.shift(252) - 1,其中 close 是“行 = 日期、列 = 股票”的宽表。

2.3 预处理:去极值、标准化、中性化

原始因子不能直接拿来比较,有三个问题:① 极端值会主导统计量;② 量纲不同,EP 是百分比、换手率是小数,不能直接相加;③ 混入了别的东西,比如很多因子和市值、行业高度相关,你以为发现了新因子,其实只是重新发现了“小盘股效应”。三个步骤分别解决这三个问题。

① 去极值(MAD 法)

直觉:如果 499 只股票的因子在 −3 到 3 之间,而 1 只因为数据错误是 300,它会单独决定均值和标准差。我们需要一个不受极端值影响的“中心”和“尺度”。均值和标准差都会被极端值拉动,而中位数 (median)和绝对中位差 (Median Absolute Deviation, MAD)不会。

$$\text{MAD}=\operatorname{median}_i\big(|x_i-\operatorname{median}(x)|\big),\qquad \hat\sigma = 1.4826\times\text{MAD}$$

常数 1.4826 的作用:当数据服从正态分布时,\(1.4826\times\text{MAD}\) 恰好约等于标准差,于是“\(k\) 倍 \(\hat\sigma\)”就有了和“\(k\) 倍标准差”类似的含义。去极值规则:把超出 \([\operatorname{median}-k\hat\sigma,\ \operatorname{median}+k\hat\sigma]\) 的值截断到边界(不是删除),\(k\) 常取 3 或 5。

手算:\(x=(1,2,3,4,100)\),\(k=3\)。中位数 = 3;绝对离差 \(=(2,1,0,1,97)\),其中位数 MAD = 1;\(\hat\sigma=1.4826\);边界 \(=3\pm4.448=[-1.448,\ 7.448]\)。所以 100 被截断成 7.448,其它值不变。对比:原始均值是 22,标准差约 43.6——一个错误值让所有统计量都失去了意义。

② 标准化

Z-score 标准化 (z-score):\(z_i=(x_i-\bar x)/s_x\),每一期在截面上单独做。之后不同因子都是“均值 0、标准差 1”,可以相加。另一种选择是排序标准化 (rank transform):把因子换成截面排名再映射到 \([0,1]\) 或正态分位数,对极端值更稳健,但丢掉了“差距有多大”的信息。

③ 中性化

直觉:如果一个因子高分的股票大多是小盘股,那么它的收益可能只是“小盘股效应”。中性化 (neutralization)就是在每一期截面上,把因子对“我们不想要的暴露”做回归,只保留残差。

$$f_i = \sum_{k=1}^{K}\beta_k\,D_{i,k} + \gamma\,\text{Size}_i + \varepsilon_i,\qquad f^{\text{neu}}_i=\hat\varepsilon_i$$
符号含义
\(f_i\)股票 \(i\) 标准化后的因子值
\(D_{i,k}\)行业哑变量 (dummy variable):股票 \(i\) 属于行业 \(k\) 时为 1,否则为 0
\(\text{Size}_i\)标准化后的对数市值
\(\beta_k,\gamma\)回归系数:\(\beta_k\) 就是行业 \(k\) 的平均因子水平
\(\hat\varepsilon_i\)残差:因子中不能被行业和市值解释的部分

由 前置知识 C 节 的 OLS 性质,残差与每个行业哑变量、与市值都不相关——所以中性化后的因子在每个行业里均值为 0、与市值的截面相关为 0。注意行业哑变量已经起到“截距”的作用,不要再额外加一列常数(否则矩阵共线)。

"""ch2_sim.py —— 生成一个“教学用”模拟股票面板。所有数据均为随机生成,不对应任何真实股票。"""
import numpy as np
import pandas as pd

def make_panel(n_stocks=500, n_months=72, n_ind=10, ic_true=0.03, persist=0.8, seed=7):
    rng = np.random.default_rng(seed)
    codes = [f"S{i:04d}" for i in range(n_stocks)]
    months = pd.period_range("2019-01", periods=n_months, freq="M")
    industry = rng.integers(0, n_ind, n_stocks)                  # 每只股票固定属于一个行业
    log_mcap0 = rng.normal(23, 1.0, n_stocks)                    # 对数市值(约 1e10 元量级)
    alpha = rng.standard_normal(n_stocks)                        # 真实“好坏”信号(不可直接观测)
    alpha2 = rng.standard_normal(n_stocks)                       # 另一个独立的、较弱的真实信号
    rows = []
    for t, m in enumerate(months):
        # 真实信号随时间缓慢变化:persist 越高,信号越持久(因子换手越低)
        alpha = persist * alpha + np.sqrt(1 - persist**2) * rng.standard_normal(n_stocks)
        alpha2 = persist * alpha2 + np.sqrt(1 - persist**2) * rng.standard_normal(n_stocks)
        log_mcap = log_mcap0 + 0.05 * rng.standard_normal(n_stocks)
        size_z = (log_mcap - log_mcap.mean()) / log_mcap.std()
        # 我们观测到的“原始因子” = 真实信号 + 市值暴露 + 噪声,并混入少量极端值
        raw = alpha + 0.8 * size_z + 0.7 * rng.standard_normal(n_stocks)
        raw = np.where(rng.random(n_stocks) < 0.01, raw * 15, raw)       # 1% 的脏数据/极端值
        # 第二个因子:主要反映 alpha2,并带一点 alpha 的成分和更多噪声
        raw2 = alpha2 + 0.3 * alpha + 1.0 * rng.standard_normal(n_stocks)
        # 下月收益 = 行业效应 + 小市值效应 + 真实 alpha + 特质噪声(月度)
        ind_ret = rng.normal(0, 0.04, n_ind)[industry]
        noise_sd = 0.10
        fwd_ret = ind_ret - 0.01 * size_z + ic_true * noise_sd * (alpha + 0.7 * alpha2) + noise_sd * rng.standard_normal(n_stocks)
        rows.append(pd.DataFrame({"month": m, "code": codes, "industry": industry,
                                  "log_mcap": log_mcap, "factor_raw": raw, "factor2_raw": raw2, "fwd_ret": fwd_ret}))
    return pd.concat(rows, ignore_index=True)

ch2_sim.py 只是“造数据”的脚本:我们故意让原始因子 = 真实信号 + 0.8 × 市值暴露 + 噪声,再混入 1% 的极端值,并让收益里含有行业效应和小市值效应。这样就能检验预处理是否真的把这些“杂质”去掉了。

import numpy as np
import pandas as pd
from ch2_sim import make_panel

def winsorize_mad(x: pd.Series, k: float = 5.0) -> pd.Series:
    """MAD 去极值:把超出 中位数 ± k×1.4826×MAD 的值“拉回”到边界上。"""
    med = x.median()
    mad = (x - med).abs().median()            # 绝对离差的中位数
    sigma = 1.4826 * mad                      # 正态分布下 1.4826×MAD ≈ 标准差
    return x.clip(med - k * sigma, med + k * sigma)

def zscore(x: pd.Series) -> pd.Series:
    """标准化:减均值、除标准差,让不同因子处于同一量纲。"""
    return (x - x.mean()) / x.std()

def neutralize(f: pd.Series, industry: pd.Series, log_mcap: pd.Series) -> pd.Series:
    """行业 + 市值中性化:对 [行业哑变量, 对数市值] 做截面回归,取残差。"""
    X = pd.get_dummies(industry, prefix="ind", dtype=float)   # 每个行业一列 0/1,相当于各行业有自己的截距
    X["size"] = zscore(log_mcap)
    beta, *_ = np.linalg.lstsq(X.values, f.values, rcond=None)  # 最小二乘求回归系数
    resid = f.values - X.values @ beta                          # 残差 = 因子中无法被行业/市值解释的部分
    return pd.Series(resid, index=f.index)

if __name__ == "__main__":                  # 被其它脚本 import 时不执行下面的演示
    panel = make_panel()
    cs = panel[panel["month"] == panel["month"].iloc[0]].copy()     # 取第一个月的截面

    cs["f_w"] = winsorize_mad(cs["factor_raw"])
    cs["f_z"] = zscore(cs["f_w"])
    cs["f_n"] = zscore(neutralize(cs["f_z"], cs["industry"], cs["log_mcap"]))

    def describe(s):
        return f"min={s.min():7.2f} max={s.max():7.2f} 偏度={s.skew():6.2f} 与市值相关={s.corr(cs['log_mcap']):5.2f}"
    print("原始因子    ", describe(cs["factor_raw"]))
    print("去极值后    ", describe(cs["f_w"]))
    print("标准化后    ", describe(cs["f_z"]))

2.4 IC、RankIC、ICIR:因子有没有预测力

直觉

如果一个因子有用,那么在每一期,因子值高的股票下一期收益也应该偏高。衡量“偏高多少”最直接的方法就是计算两者在截面上的相关系数。

定义

指标公式含义
IC (Information Coefficient)\(\text{IC}_t=\operatorname{corr}\big(f_{\cdot,t},\,r_{\cdot,t+1}\big)\)第 \(t\) 期因子与下期收益的 Pearson 截面相关
RankIC (Spearman rank IC)\(\operatorname{corr}\big(\operatorname{rank}(f),\operatorname{rank}(r)\big)\)先排名再求相关;不受极端值影响,更常用
ICIR (IC Information Ratio)\(\overline{\text{IC}}/\operatorname{std}(\text{IC})\)IC 的“夏普比率”:预测力有多稳定
IC 的 t 值\(t=\overline{\text{IC}}\big/\big(\operatorname{std}(\text{IC})/\sqrt{T}\big)=\text{ICIR}\times\sqrt T\)\(T\) 期 IC 均值是否显著不为 0
手算 RankIC:5 只股票,因子 \(f=(1.2,-0.5,0.3,2.0,-1.0)\),下期收益 \(r=(2\%,-1\%,1\%,0.5\%,-2\%)\)。
  1. 因子排名(从小到大记 1–5):\((4,2,3,5,1)\);收益排名:\((5,2,4,3,1)\)。
  2. 排名差 \(d=(-1,0,-1,2,0)\),\(\sum d^2=6\)。
  3. 无并列时 Spearman 公式:\(\rho=1-\dfrac{6\sum d^2}{n(n^2-1)}=1-\dfrac{36}{5\times24}=0.70\)。
这一期 RankIC = 0.70。真实市场里单期 IC 通常小得多,而且正负交替——所以我们关心的是很多期 IC 的均值和稳定性。
为什么很小的 IC 也可能有价值?主动管理里有一个著名的近似关系——主动管理基本定律 (Fundamental Law of Active Management, Grinold):\(\text{IR}\approx\text{IC}\times\sqrt{\text{BR}}\),其中 IR 是主动收益的信息比率,BR(breadth)是每年独立下注的次数。截面上几百只股票、每月调仓,下注次数很多,所以即使每次预测只“好一点点”,累积起来也可能可观。但这个定律假设各次下注相互独立、没有成本,现实中要打折扣。

    g = g.copy()
    g["factor"] = zscore(neutralize(f, g["industry"], g["log_mcap"]))
    return g

# ---- 1) 每期 IC 与 RankIC ----

ic = by_m.apply(lambda g: g["factor"].corr(g["fwd_ret"]))                      # Pearson IC
ric = by_m.apply(lambda g: g["factor"].corr(g["fwd_ret"], method="spearman"))  # 秩相关 RankIC
icir = ric.mean() / ric.std()                                                  # 信息比率 ICIR(月度)
t_stat = ric.mean() / (ric.std() / np.sqrt(len(ric)))                          # 均值是否显著不为 0
print(f"期数={len(ric)}  IC均值={ic.mean():.4f}  RankIC均值={ric.mean():.4f}  RankIC标准差={ric.std():.4f}")
print(f"ICIR={icir:.3f}  年化ICIR≈{icir*np.sqrt(12):.2f}  t值={t_stat:.2f}  RankIC>0 占比={(ric>0).mean():.1%}")

# ---- 2) 分层(分位数)回测:每期按因子分 5 组,看各组下月平均收益 ----
panel["q"] = by_m["factor"].transform(lambda s: pd.qcut(s, 5, labels=False) + 1)
q_ret = panel.groupby(["month", "q"])["fwd_ret"].mean().unstack()   # 行=月份,列=组别 1..5
print("\n各组月均收益(%):", (q_ret.mean() * 100).round(3).to_dict())
ls = q_ret[5] - q_ret[1]                                            # 多空组合:做多第5组、做空第1组
print(f"多空月均收益={ls.mean():.4%}  年化夏普≈{ls.mean()/ls.std()*np.sqrt(12):.2f}")

# ---- 3) 换手率:第 5 组成分股每月有多少比例被换掉 ----
top = panel[panel["q"] == 5].groupby("month")["code"].apply(set)
turnover = [1 - len(a & b) / len(b) for a, b in zip(top[:-1], top[1:])]
print(f"第5组平均月换手率={np.mean(turnover):.1%}")

# ---- 4) 因子衰减:用 t 月因子去预测 t+h 月收益 ----
wide_f = panel.pivot(index="month", columns="code", values="factor")
wide_r = panel.pivot(index="month", columns="code", values="fwd_ret")
for h in [0, 1, 2, 3, 6]:
    ics = [wide_f.iloc[t].corr(wide_r.iloc[t + h], method="spearman") for t in range(len(wide_f) - h)]
    print(f"滞后 {h} 期的 RankIC 均值: {np.mean(ics):.4f}")

2.5 分层回测

做法

  1. 每个调仓日,按因子值把股票池分成 \(Q\) 组(常用 5 或 10 组),组 1 因子最小、组 \(Q\) 最大;
  2. 每组内部等权(或市值加权)持有到下一调仓日,记录组收益;
  3. 画出每组的累计净值,看是否单调分层;计算“组 \(Q\) − 组 1”的多空收益。

和 IC 的关系

IC 衡量“整体排序”的相关性,分层回测衡量“可以赚多少钱”。两者可能不一致:例如一个因子只在尾部有效(能识别“雷”,但分不出好股票),IC 不高,但做多“非尾部”可能仍有价值。所以两者都要看。

分层回测的三个细节:① 组内等权会放大小盘股的影响,建议同时看市值加权结果;② 每期股票数量变化时,分组边界也会变化,要使用 point-in-time 股票池;③ 剔除停牌、涨停买不进的股票(第 1 章),否则头部组的收益会虚高。

2.6 因子衰减与换手

直觉

因子的信息会“过期”。因子衰减 (alpha decay)描述的是:用 \(t\) 期的因子去预测 \(t+h\) 期的收益,IC 随 \(h\) 增大下降得有多快。衰减慢的因子可以低频调仓、交易成本低;衰减快的因子必须频繁调仓,成本可能吃掉全部收益。

换手与成本的量化

定义头部组的换手率 (turnover)为:本期成分中“上期不在组内”的比例。若每期换手 \(\tau\),单边成本 \(c\),则每期成本约为 \(2\tau c\)(卖出旧的、买入新的各一次)。

数值例子:下面代码给出头部组月换手约 54%。若单边成本 0.15%(含佣金、税、冲击的粗略假设),每月成本 \(\approx 2\times0.54\times0.15\%=0.16\%\),一年约 1.9%。把它和多空(或多头超额)年化收益比较,才能判断因子是否“扣完成本还有剩”。

因子越持久(相邻两期因子值的截面相关越高),换手越低。在模拟数据里我们设定了 0.8 的月度持续性,所以 54% 的换手完全来自“排名在边界附近来回跳”。降低换手的常见方法:① 降低调仓频率;② 对因子做时间平滑(例如取过去 3 个月均值);③ 设置“缓冲区”——已持有的股票跌出前 20% 才卖,新股票进入前 15% 才买。

2.7 多因子合成

直觉

单个因子的 IC 都不高,但如果几个因子包含不同的信息,把它们合在一起,噪声会部分抵消,信号会叠加。关键词是“不同”:两个高度相关的因子合成,几乎没有收益;两个独立的弱因子合成,可能明显提高 ICIR。

三种常见方法

  1. 等权:\(F=\frac1K\sum_k z_k\)。简单、稳健,不需要估计任何参数。
  2. ICIR 加权:权重 \(\propto\) 每个因子过去一段窗口的 ICIR(负值置 0)。给“历史上更稳定”的因子更大权重。
  3. 最大化 ICIR 加权:若各因子 IC 序列的均值向量为 \(\bar{\mathbf{IC}}\)、协方差矩阵为 \(\Sigma_{IC}\),则使合成因子 ICIR 最大的权重近似为 \(w\propto\Sigma_{IC}^{-1}\bar{\mathbf{IC}}\)——这和第 4 章最大夏普组合的公式形式完全相同。它考虑了因子之间的相关,但需要估计协方差,样本少时不稳定。

import numpy as np
import pandas as pd
from ch2_sim import make_panel
from ch2_preprocess import winsorize_mad, zscore, neutralize

panel = make_panel()

def clean(g, col):
    """去极值 → 标准化 → 中性化 → 再标准化,返回干净的因子暴露。"""
    f = zscore(winsorize_mad(g[col]))
    return zscore(neutralize(f, g["industry"], g["log_mcap"]))

parts = []
for m, g in panel.groupby("month"):
    g = g.copy()
    g["f1"], g["f2"] = clean(g, "factor_raw"), clean(g, "factor2_raw")
    parts.append(g)
panel = pd.concat(parts, ignore_index=True)

def rank_ic(df, col):
    return df.groupby("month").apply(lambda g: g[col].corr(g["fwd_ret"], method="spearman"))

ic1, ic2 = rank_ic(panel, "f1"), rank_ic(panel, "f2")
print(f"f1 与 f2 的平均截面相关: {panel.groupby('month').apply(lambda g: g['f1'].corr(g['f2'])).mean():.2f}")

# 方法 A:等权合成
panel["eq"] = (panel["f1"] + panel["f2"]) / 2
# 方法 B:按“过去 12 个月”的 ICIR 加权 —— 权重只用历史信息,避免未来函数
icir1 = (ic1.rolling(12).mean() / ic1.rolling(12).std()).shift(1)   # shift(1):本月只能用到上月为止
icir2 = (ic2.rolling(12).mean() / ic2.rolling(12).std()).shift(1)
w1 = icir1.clip(lower=0) / (icir1.clip(lower=0) + icir2.clip(lower=0))  # 负的 ICIR 不给权重
panel["w1"] = panel["month"].map(w1)
panel["icir_w"] = panel["w1"] * panel["f1"] + (1 - panel["w1"]) * panel["f2"]
valid = panel.dropna(subset=["icir_w"])                                    # 前 13 个月没有足够历史

for name in ["f1", "f2", "eq", "icir_w"]:
    r = rank_ic(valid, name)
    print(f"{name:7s} RankIC均值={r.mean():.4f}  ICIR={r.mean()/r.std():.3f}")
print(f"ICIR 加权中 f1 的平均权重: {w1.mean():.2f}")

补充:Fama-MacBeth 回归

另一种检验因子的经典方法是 Fama-MacBeth 两步回归 (Fama-MacBeth regression)(Fama & MacBeth, 1973):每一期在截面上做回归 \(r_{i,t+1}=a_t+\lambda_t f_{i,t}+e_{i,t+1}\),得到一串 \(\lambda_t\)(称为该期的因子收益 (factor return)),再检验 \(\lambda_t\) 的均值是否显著不为 0。它和 IC 思路一致,好处是可以同时放入多个因子,看“控制了其它因子后”某个因子还有没有增量信息。

2.8 一份完整的因子报告应包含什么

开源工具 Alphalens(原 Quantopian 项目,社区维护版为 alphalens-reloaded)把因子检验整理成标准报告。即使不用它,你自己的报告也建议包含:

  • 因子分布:每期覆盖股票数、缺失比例、分位数;
  • IC / RankIC 的时间序列、均值、标准差、ICIR、t 值、IC>0 占比,以及按年份、按市场环境拆开的 IC;
  • 分层收益(等权 + 市值加权)、多空收益、头部组相对基准的超额收益;
  • IC 衰减曲线、头部组换手率、扣成本后的收益;
  • 与已知因子(市值、行业、动量、价值……)的相关性,判断是否“新”。

2.9 常见错误

  • ❌ 因子在 \(t\) 日收盘计算,却和 \(t\) 日的收益对齐 → 未来函数。✅ 因子永远对齐下一期收益(fwd_ret)。
  • ❌ 用全样本(而不是每期截面)做标准化或去极值 → 把未来的分布信息带到过去。✅ 所有预处理在每期截面内单独完成。
  • ❌ 只看 IC 不看分层、只看多空不看成本 → 高估可实现收益。
  • ❌ 没有中性化就宣称发现了新因子 → 可能只是市值或行业的“马甲”。
  • ❌ 试了 200 个因子,只报告 t 值最高的那个 → 多重检验问题(第 7 章)。
  • ❌ 用全样本 ICIR 给因子定权重 → 未来函数。

2.10 本章小结

  • 因子研究是截面问题:同一时点,哪些股票相对更好。
  • 预处理三步:MAD 去极值(稳健)、标准化(统一量纲)、中性化(回归取残差,剔除行业/市值暴露)。
  • IC/RankIC 衡量预测力,ICIR 衡量稳定性,\(t=\text{ICIR}\sqrt T\);分层回测检验单调性和可实现收益。
  • 衰减决定调仓频率,换手决定成本;每期成本 ≈ \(2\tau c\)。
  • 多因子合成的价值来自信息的独立性;复杂加权未必胜过等权,且权重只能用历史数据估计。

3.1 平稳性:为什么它是一切的前提

直觉

几乎所有统计方法都隐含一个假设:过去的规律在未来仍然成立。如果一个序列的均值、波动、相关结构一直在变,那么“用过去估计参数、用来预测未来”就没有依据。平稳 (stationary)的序列就是“统计性质不随时间变化”的序列。

定义(弱平稳)

序列 \(\{x_t\}\) 称为弱平稳,如果对所有 \(t\) 和滞后 \(h\):

  1. 均值恒定:\(E[x_t]=\mu\);
  2. 方差有限且恒定:\(\operatorname{Var}(x_t)=\sigma^2<\infty\);
  3. 自协方差只取决于间隔:\(\operatorname{Cov}(x_t,x_{t-h})=\gamma_h\),与 \(t\) 无关。

价格通常不平稳,收益率通常(近似)平稳。最典型的非平稳序列是随机游走 (random walk) \(x_t=x_{t-1}+\varepsilon_t\):它的方差 \(\operatorname{Var}(x_t)=t\sigma^2\) 随时间无限增大。对数价格大致就是随机游走,而它的一阶差分——对数收益率——就是 \(\varepsilon_t\),是平稳的。

伪回归 (spurious regression):把两条互不相关的随机游走做回归,经常会得到很高的 \(R^2\) 和“显著”的 t 值。这是因为两个都在漂移的序列在有限样本里看起来总像有关系。所以:不要直接拿价格对价格做回归来找关系,除非你在检验协整(3.5 节)。

3.2 单位根与 ADF 检验

思路

考虑 AR(1) 模型 \(x_t=\phi x_{t-1}+\varepsilon_t\)。如果 \(|\phi|<1\),冲击会逐渐消失,序列是平稳的;如果 \(\phi=1\),就是随机游走,称为有单位根 (unit root)。两边同时减去 \(x_{t-1}\):

$$\Delta x_t = \gamma\,x_{t-1}+\varepsilon_t,\qquad \gamma=\phi-1 .$$

检验 \(\phi=1\) 就等价于检验 \(\gamma=0\)。ADF 检验 (Augmented Dickey-Fuller test)在右边再加入常数项和若干阶 \(\Delta x_{t-i}\)(“增广”部分,用来吸收残差的自相关):

$$\Delta x_t=\alpha+\gamma x_{t-1}+\sum_{i=1}^{p}\delta_i\,\Delta x_{t-i}+\varepsilon_t$$
  • 原假设 H₀:\(\gamma=0\)(有单位根、非平稳);备择假设:\(\gamma<0\)(平稳)。
  • 检验统计量是 \(\hat\gamma\) 的 t 值,但在 H₀ 下它不服从通常的 t 分布,而服从 Dickey-Fuller 分布,临界值更“负”(5% 水平约 −2.86,而不是 −1.65)。
  • 滞后阶数 \(p\) 一般用信息准则(AIC/BIC)自动选择。
📄 ch3_adf.py
import numpy as np
from statsmodels.tsa.stattools import adfuller

rng = np.random.default_rng(1)
n = 1000
eps = rng.standard_normal(n)

random_walk = np.cumsum(eps)                  # 随机游走:x_t = x_{t-1} + ε_t(单位根,非平稳)
ar1 = np.zeros(n)                             # AR(1):x_t = 0.9·x_{t-1} + ε_t(平稳)
for t in range(1, n):
    ar1[t] = 0.9 * ar1[t - 1] + eps[t]
log_price = 4.6 + np.cumsum(0.0003 + 0.015 * rng.standard_normal(n))  # 模拟对数价格:带漂移的随机游走
log_ret = np.diff(log_price)                  # 对数收益率 = 对数价格的一阶差分

for name, x in [("随机游走", random_walk), ("AR(1) φ=0.9", ar1),
                ("模拟对数价格", log_price), ("模拟对数收益率", log_ret)]:
    res = adfuller(x, autolag="AIC")          # 自动用 AIC 选择差分滞后阶数
    stat, pvalue, crit = res[0], res[1], res[4]   # 检验统计量、p 值、临界值字典
    verdict = "拒绝单位根 → 平稳" if pvalue < 0.05 else "不能拒绝单位根 → 视为非平稳"
    print(f"{name:12s} ADF统计量={stat:7.3f}  p值={pvalue:.4f}  5%临界值={crit['5%']:.3f}  {verdict}")

解读:随机游走和模拟对数价格的 p 值都很大(不能拒绝单位根);AR(1) φ=0.9 和对数收益率的统计量远小于 5% 临界值 −2.864,拒绝单位根。注意 φ=0.9 的序列看起来也像在漂移,但它终究会回归——ADF 正是用来区分这两种情况的。

ADF 的局限:① 它的检验功效不高:φ=0.98 这种“接近单位根”的平稳序列,在样本不长时常常无法拒绝 H₀;② 结论依赖于是否包含常数项、趋势项(regression="c" 或 "ct");③ “不能拒绝 H₀”≠“证明了非平稳”。可以配合 KPSS 检验(原假设与 ADF 相反,为“平稳”)一起看。

3.3 ARIMA:对序列的“记忆”建模

三个积木

模型方程直觉
AR(p)
自回归 Autoregressive		\(x_t=c+\sum_{i=1}^p\phi_i x_{t-i}+\varepsilon_t\)今天和过去几天的值有关
MA(q)
移动平均 Moving Average		\(x_t=\mu+\varepsilon_t+\sum_{j=1}^q\theta_j\varepsilon_{t-j}\)今天和过去几天的冲击有关(注意:和技术分析里的“均线”不是一回事)
ARIMA(p,d,q)对 \(x_t\) 差分 \(d\) 次后做 ARMA(p,q)\(d=1\) 用来处理有单位根的序列,如对价格建模等价于对收益建模

其中 \(\varepsilon_t\) 是白噪声 (white noise):均值 0、方差恒定、互不相关。

AR(1) 的均值回归形式

把 AR(1) 写成 \(r_t-\mu=\phi(r_{t-1}-\mu)+\varepsilon_t\),其中 \(\mu=c/(1-\phi)\) 是长期均值。它的含义是:今天偏离均值的部分,明天只剩 \(\phi\) 倍。偏离衰减一半所需的期数——半衰期 (half-life)——为

$$h_{1/2}=\frac{\ln 0.5}{\ln\phi}.$$
数值例子:\(\mu=0.03\%\),\(\phi=0.1\),昨天收益 \(r_{t-1}=2\%\)。今天的预测值 \(=0.0003+0.1\times(0.02-0.0003)=0.227\%\)。半衰期 \(=\ln0.5/\ln0.1\approx0.3\) 天——几乎立刻消失。而 \(\phi=0.95\) 时半衰期约 13.5 天。

怎么选阶数、怎么验证

  • AIC (Akaike Information Criterion) \(=2k-2\ln L\)(\(k\) 为参数个数,\(L\) 为似然):在拟合优度与复杂度之间权衡,越小越好。BIC 对参数的惩罚更重。
  • 拟合后检查残差:如果模型抓住了所有线性结构,残差应该接近白噪声。Ljung-Box 检验 (Ljung-Box test)的原假设是“前 \(m\) 阶自相关全为 0”,p 值大说明没发现剩余结构。
📄 ch3_arima.py
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox

rng = np.random.default_rng(2)
n, mu, phi, sigma = 1500, 0.0003, 0.10, 0.012       # 真实参数:均值、AR 系数、噪声标准差
r = np.zeros(n)
for t in range(1, n):                               # 生成 AR(1) 收益率:r_t − μ = φ(r_{t-1} − μ) + ε_t
    r[t] = mu + phi * (r[t - 1] - mu) + sigma * rng.standard_normal()

model = ARIMA(r, order=(1, 0, 0))                   # (p, d, q) = (1, 0, 0):AR(1),不差分,无 MA 项
res = model.fit()
const, ar_l1, s2 = res.params                       # 估计的常数(=均值)、AR 系数、残差方差
print(f"估计 μ={const:.5f}  φ={ar_l1:.3f} (标准误 {res.bse[1]:.3f})  σ={np.sqrt(s2):.4f}")
print(f"AIC={res.aic:.1f}")

lb = acorr_ljungbox(res.resid, lags=[10])           # 残差还有没有自相关?p 值大 = 没有明显剩余结构
print(f"残差 Ljung-Box(10) p值={lb['lb_pvalue'].iloc[0]:.3f}")

fc = res.get_forecast(steps=3)                      # 向前预测 3 步
print("未来 3 天预测均值:", np.round(fc.predicted_mean, 5))
print("95% 区间下限:", np.round(fc.conf_int()[:, 0], 4))

3.4 GARCH:波动率会聚集

直觉

观察任何一段市场行情都会发现:大波动之后往往跟着大波动,平静之后往往跟着平静——这叫波动率聚集 (volatility clustering)。入门站把波动率当作常数,但对风险管理、仓位控制(波动率目标法)、期权定价来说,“明天的波动率是多少”才是关键。

模型

GARCH(1,1) (Generalized Autoregressive Conditional Heteroskedasticity)(Bollerslev, 1986,推广了 Engle 1982 年的 ARCH 模型):

$$r_t=\sigma_t z_t,\quad z_t\sim N(0,1);\qquad \sigma_t^2=\omega+\alpha\,r_{t-1}^2+\beta\,\sigma_{t-1}^2$$
符号含义直觉
\(\sigma_t^2\)条件方差 (conditional variance):基于 \(t-1\) 时刻信息对 \(t\) 日方差的预测“明天的波动率”
\(\omega>0\)常数项决定长期水平
\(\alpha\ge0\)对昨天“意外”(\(r_{t-1}^2\))的反应新闻冲击有多大影响
\(\beta\ge0\)对昨天波动预测的记忆波动有多“粘”
\(\alpha+\beta<1\)持续性 (persistence)越接近 1,冲击消退越慢

由此可以推出两个常用结论:

  • 长期(无条件)方差:\(\bar\sigma^2=\dfrac{\omega}{1-\alpha-\beta}\)。
  • 多步预测:\(E_t[\sigma_{t+h}^2]=\bar\sigma^2+(\alpha+\beta)^{h-1}\big(\sigma_{t+1}^2-\bar\sigma^2\big)\)——波动预测以 \(\alpha+\beta\) 的速度向长期水平回归,半衰期 \(=\ln0.5/\ln(\alpha+\beta)\)。
数值例子:\(\omega=2\times10^{-6}\),\(\alpha=0.08\),\(\beta=0.90\)。
  1. 长期日方差 \(=2\times10^{-6}/0.02=10^{-4}\),即日波动 1%,年化 \(\approx1\%\times\sqrt{252}=15.9\%\)。
  2. 假设昨天 \(\sigma_{t-1}^2=10^{-4}\),昨天收益 \(-3\%\):今天 \(\sigma_t^2=2\times10^{-6}+0.08\times0.0009+0.9\times0.0001=1.64\times10^{-4}\),日波动从 1% 升到 1.28%。
  3. 持续性 0.98 → 半衰期 \(=\ln0.5/\ln0.98\approx34\) 个交易日。

估计:极大似然

极大似然估计 (Maximum Likelihood Estimation, MLE)的思路:找一组参数,使“观测到这串收益”的概率最大。在正态假设下,每天的对数似然是 \(-\tfrac12\big[\ln(2\pi)+\ln\sigma_t^2+r_t^2/\sigma_t^2\big]\),把所有天加起来再取负号,交给优化器最小化即可。下面的代码不依赖专门的库,自己实现了这一过程(实际工作中可用 arch 库,它提供更多模型变体和稳健标准误)。

📄 ch3_garch.py
import numpy as np
from scipy.optimize import minimize

rng = np.random.default_rng(3)
# ---- 1) 用已知参数模拟一条 GARCH(1,1) 日收益率序列 ----
omega, alpha, beta, n = 2e-6, 0.08, 0.90, 3000
r, s2 = np.zeros(n), np.zeros(n)
s2[0] = omega / (1 - alpha - beta)                 # 从长期方差开始
for t in range(n):
    if t > 0:
        s2[t] = omega + alpha * r[t - 1]**2 + beta * s2[t - 1]   # 条件方差递推
    r[t] = np.sqrt(s2[t]) * rng.standard_normal()                 # 收益 = 条件波动 × 标准正态

# ---- 2) 极大似然估计:最小化负对数似然 ----
def neg_loglik(params, r):
    w, a, b = params
    if w <= 0 or a < 0 or b < 0 or a + b >= 1:     # 不满足约束 → 返回极大值,让优化器避开
        return 1e10
    var = np.empty_like(r)
    var[0] = r.var()                               # 初值:用样本方差
    for t in range(1, len(r)):
        var[t] = w + a * r[t - 1]**2 + b * var[t - 1]
    return 0.5 * np.sum(np.log(2 * np.pi) + np.log(var) + r**2 / var)

x0 = [r.var() * 0.05, 0.05, 0.90]                  # 合理的初始猜测
opt = minimize(neg_loglik, x0, args=(r,), method="Nelder-Mead",
               options={"maxiter": 4000, "xatol": 1e-10, "fatol": 1e-6})
w_hat, a_hat, b_hat = opt.x
print(f"真实: ω={omega:.2e} α={alpha:.3f} β={beta:.3f}")
print(f"估计: ω={w_hat:.2e} α={a_hat:.3f} β={b_hat:.3f}  α+β={a_hat+b_hat:.3f}")
long_run_vol = np.sqrt(w_hat / (1 - a_hat - b_hat) * 252)
print(f"长期年化波动率≈{long_run_vol:.1%}  (真实值 {np.sqrt(omega/(1-alpha-beta)*252):.1%})")
half_life = np.log(0.5) / np.log(a_hat + b_hat)
print(f"波动冲击半衰期≈{half_life:.1f} 个交易日")

# ---- 3) 向前预测:h 步后的方差向长期方差回归 ----
var_f = np.empty_like(r)                            # 用“估计出的参数”重新滤波得到条件方差序列
var_f[0] = r.var()
for t in range(1, n):
    var_f[t] = w_hat + a_hat * r[t - 1]**2 + b_hat * var_f[t - 1]
var_T = w_hat + a_hat * r[-1]**2 + b_hat * var_f[-1]   # 明天(T+1)的条件方差
lr_var = w_hat / (1 - a_hat - b_hat)
for h in [1, 5, 20, 60]:
    v = lr_var + (a_hat + b_hat)**(h - 1) * (var_T - lr_var)
    print(f"{h:3d} 天后的日波动率预测: {np.sqrt(v):.4%}")

3.5 协整进阶:Engle-Granger 两步法

直觉

两只股票各自是随机游走(不平稳),但如果它们被同一个经济因素“拴在一起”,它们的某个线性组合(价差)可能是平稳的,会围绕均值来回摆动——这就是协整 (cointegration)(Engle & Granger, 1987)。配对交易押注的正是“价差会回归”。

两步法

  1. 估计关系:OLS 回归 \(y_t=c+\beta x_t+u_t\),得到对冲比率 (hedge ratio) \(\hat\beta\),价差 \(\hat u_t=y_t-\hat c-\hat\beta x_t\)。
  2. 检验价差平稳:对 \(\hat u_t\) 做 ADF 型检验。由于 \(\hat\beta\) 是“为了让残差最小”而估计出来的,残差天然显得更平稳,所以必须使用 Engle-Granger 专用临界值(比普通 ADF 更严格)。statsmodels.tsa.stattools.coint 已经处理了这一点。

半衰期与交易信号

对价差回归 \(\Delta u_t=\lambda u_{t-1}+e_t\)(这是离散版的OU 过程 (Ornstein-Uhlenbeck process)),\(\lambda<0\) 表示回归,半衰期 \(=-\ln2/\lambda\)。半衰期决定持仓周期:半衰期 10 天的价差适合日频交易,半衰期 200 天的价差则几乎不可交易。交易信号常用 \(z_t=(u_t-\bar u)/s_u\):\(|z|>2\) 开仓,回到 0 附近平仓。

📄 ch3_coint.py
import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.stattools import coint, adfuller

rng = np.random.default_rng(4)
n = 750
# 共同的随机趋势 + 各自的平稳偏离 → 两个价格序列协整(模拟数据)
common = np.cumsum(rng.normal(0, 1, n))
spread_true = np.zeros(n)
for t in range(1, n):                                  # 价差服从 AR(1),φ=0.95,会回归
    spread_true[t] = 0.95 * spread_true[t - 1] + rng.normal(0, 1)
x = 50 + common                                        # 资产 X
y = 10 + 1.5 * x + spread_true                         # 资产 Y = 常数 + 1.5·X + 平稳价差

# 第 1 步:OLS 回归 y = c + β·x,得到对冲比率 β
ols = sm.OLS(y, sm.add_constant(x)).fit()
c_hat, beta_hat = ols.params
spread = y - c_hat - beta_hat * x
print(f"对冲比率 β 估计={beta_hat:.3f}  (真实 1.5)")

# 第 2 步:检验残差(价差)是否平稳 —— 用 coint() 而不是直接 adfuller(),
# 因为残差是“估计出来的”,临界值需要用 Engle-Granger 专门的表
t_stat, p_value, crit = coint(y, x)
print(f"Engle-Granger 检验: 统计量={t_stat:.3f}  p值={p_value:.4f}  5%临界值={crit[1]:.3f}")
print(f"(对照)直接对价差做 ADF 的 p 值={adfuller(spread)[1]:.4f} —— 偏乐观,不应这样用")

# 第 3 步:均值回归半衰期:Δs_t = λ·s_{t-1} + 误差,半衰期 = −ln2 / λ
ds, s_lag = np.diff(spread), spread[:-1]
lam = sm.OLS(ds, sm.add_constant(s_lag)).fit().params[1]
print(f"λ={lam:.4f}  半衰期≈{-np.log(2)/lam:.1f} 天  (真实 φ=0.95 对应 {np.log(0.5)/np.log(0.95):.1f} 天)")

# 第 4 步:z-score 信号
z = (spread - spread.mean()) / spread.std()
print(f"|z|>2 的天数占比: {(np.abs(z) > 2).mean():.1%}")

对冲比率 β 估计=1.483  (真实 1.5)
Engle-Granger 检验: 统计量=-4.678  p值=0.0006  5%临界值=-3.344
(对照)直接对价差做 ADF 的 p 值=0.0001 —— 偏乐观,不应这样用
λ=-0.0600  半衰期≈11.6 天  (真实 φ=0.95 对应 13.5 天)
|z|>2 的天数占比: 4.7%

解读:β 估计 1.483(真值 1.5);Engle-Granger p≈0.0006,协整显著;估计的半衰期 11.6 天,与真值 13.5 天同一量级。“直接 ADF”的 p 值更小——这就是为什么不能对估计出的残差直接套用普通 ADF 临界值。

样本内的协整 ≠ 未来的协整:上面 z-score 用的是全样本均值和标准差,只用于描述;交易回测中必须用滚动窗口估计 \(\beta\)、均值和标准差。另外,经济关系可能断裂(公司业务变化、并购),协整关系需要持续监控。多于两个资产时,可以用 Johansen 检验。

3.6 卡尔曼滤波:让参数随时间变化

直觉

上一节用一个固定的 \(\beta\) 描述整个样本。但真实的对冲比率会慢慢漂移。用滚动窗口 OLS 可以缓解,但窗口长度很难选:太短噪声大,太长反应慢。卡尔曼滤波 (Kalman filter)(Kalman, 1960)提供了一个更系统的答案:把 \(\beta_t\) 当作一个看不见、会慢慢变化的状态,每来一个新观测就按“新数据有多可信”来更新估计。

模型(状态空间形式)

$$\text{状态方程:}\ \beta_t=\beta_{t-1}+w_t,\ w_t\sim N(0,Q)\qquad \text{观测方程:}\ y_t=x_t\beta_t+v_t,\ v_t\sim N(0,R)$$

每一步分两段:

步骤公式含义
预测\(\hat\beta_{t|t-1}=\hat\beta_{t-1},\quad P_{t|t-1}=P_{t-1}+Q\)没有新信息时,最佳猜测不变,但不确定性 \(P\) 增加
新息\(e_t=y_t-x_t\hat\beta_{t|t-1},\quad S_t=x_t^2P_{t|t-1}+R\)预测误差及其方差
增益\(K_t=P_{t|t-1}x_t/S_t\)新数据的“话语权”:\(P\) 大(对旧估计没把握)或 \(R\) 小(观测很准)时,\(K\) 大
更新\(\hat\beta_t=\hat\beta_{t|t-1}+K_te_t,\quad P_t=(1-K_tx_t)P_{t|t-1}\)按增益修正估计,不确定性减小
手算一步:\(\hat\beta_{t-1}=1.0\),\(P_{t-1}=0.01\),\(Q=10^{-4}\),\(R=4\);今天 \(x_t=50\),\(y_t=52\)。
  1. 预测:\(P_{t|t-1}=0.0101\)。
  2. 新息:\(e_t=52-50\times1.0=2\);\(S_t=2500\times0.0101+4=29.25\)。
  3. 增益:\(K_t=0.0101\times50/29.25\approx0.01726\)。
  4. 更新:\(\hat\beta_t=1.0+0.01726\times2\approx1.0345\);\(P_t=(1-0.01726\times50)\times0.0101\approx0.00138\)。
一次 2 元的“意外”只让 β 移动了 0.035,因为观测噪声 \(R\) 相对较大;不确定性 \(P\) 则因为有了新数据而显著下降。
📄 ch3_kalman.py
import numpy as np

rng = np.random.default_rng(5)
n = 600
# 真实对冲比率 β_t 随时间缓慢漂移(模拟数据)
beta_true = 1.0 + np.cumsum(rng.normal(0.001, 0.01, n))
x = 50 + np.cumsum(rng.normal(0, 1, n))
y = beta_true * x + rng.normal(0, 2.0, n)              # 观测:y_t = β_t·x_t + 观测噪声

# 状态空间模型:
#   状态方程 β_t = β_{t-1} + w_t,  w_t ~ N(0, Q)   (β 像随机游走一样慢慢变)
#   观测方程 y_t = x_t·β_t + v_t,   v_t ~ N(0, R)
Q, R = 1e-4, 4.0                                        # 过程噪声方差 / 观测噪声方差(需调参)
beta_hat, P = 0.0, 1.0                                  # 初始估计与其不确定性(方差)
est = np.zeros(n)
for t in range(n):
    # 1) 预测:β 的最佳猜测不变,不确定性增加 Q
    P = P + Q
    # 2) 更新:看到 y_t 后,用“预测误差”修正
    y_pred = x[t] * beta_hat                            # 预测的观测值
    err = y[t] - y_pred                                 # 新息(innovation)
    S = x[t] * P * x[t] + R                             # 新息的方差
    K = P * x[t] / S                                    # 卡尔曼增益:多相信新数据还是旧估计
    beta_hat = beta_hat + K * err
    P = (1 - K * x[t]) * P
    est[t] = beta_hat

ols_beta = (x @ y) / (x @ x)                            # 对比:全样本一个固定 β(无截距)
for t in [50, 200, 400, 599]:
    print(f"t={t:3d}  真实β={beta_true[t]:.3f}  卡尔曼估计={est[t]:.3f}")
print(f"全样本 OLS 固定 β={ols_beta:.3f}")
print(f"后 400 天平均绝对误差: 卡尔曼={np.abs(est[200:]-beta_true[200:]).mean():.3f}  "
      f"固定OLS={np.abs(ols_beta-beta_true[200:]).mean():.3f}")

3.7 常见错误

  • ❌ 对价格(非平稳)直接做回归、算相关 → 伪回归。✅ 对收益做,或专门检验协整。
  • ❌ 把 ADF“不能拒绝”理解为“证明了有单位根”。
  • ❌ 对估计出的价差直接用普通 ADF 临界值 → 高估协整显著性。✅ 用 coint()(Engle-Granger 临界值)。
  • ❌ 用全样本均值/标准差计算 z-score 再回测 → 未来函数。✅ 滚动估计。
  • ❌ 认为 GARCH 能预测收益方向——它预测的是波动大小,不是涨跌。
  • ❌ 卡尔曼滤波的 \(Q,R\) 在全样本上调到最好 → 过拟合。

3.8 本章小结

  • 平稳 = 均值、方差、自协方差不随时间变化;价格通常不平稳,收益近似平稳。
  • ADF 检验 \(\Delta x_t=\alpha+\gamma x_{t-1}+\dots\) 中 \(\gamma=0\)(单位根),使用专门的临界值。
  • AR(1) 的 \(\phi\) 决定均值回归速度,半衰期 \(=\ln0.5/\ln\phi\);日收益的线性可预测性通常很弱。
  • GARCH(1,1):\(\sigma_t^2=\omega+\alpha r_{t-1}^2+\beta\sigma_{t-1}^2\);\(\alpha+\beta\) 是持续性,长期方差 \(\omega/(1-\alpha-\beta)\)。
  • 协整用 Engle-Granger 两步法检验;卡尔曼滤波让对冲比率等参数可以在线、平滑地更新。

4.1 从仓位到权重:组合的收益与风险

设有 \(N\) 个资产,权重向量 \(w\)(\(\sum_iw_i=1\)),预期收益向量 \(\mu\),协方差矩阵 \(\Sigma\)。那么组合的

$$\text{预期收益 } \mu_p=w^\top\mu,\qquad \text{方差 } \sigma_p^2=w^\top\Sigma w=\sum_{i}\sum_{j}w_iw_j\sigma_{ij}.$$

方差公式里有 \(N\) 个方差项和 \(N(N-1)\) 个协方差项。资产越多,协方差项越占主导——这说明组合风险主要由资产之间的相关性决定,而不是各自的波动。这也是分散化的数学本质。

4.2 均值-方差优化与有效前沿

直觉

马科维茨(Markowitz, 1952)提出:投资者应该在“给定预期收益下,方差最小”的组合中选择。所有这样的组合在“波动–收益”平面上连成一条曲线,称为有效前沿 (efficient frontier)。前沿以下的组合都是“浪费”的:存在另一个组合,风险相同而收益更高。

推导 1:全局最小方差组合

问题:\(\min_w\ w^\top\Sigma w\),约束 \(\mathbf 1^\top w=1\)(允许做空)。用拉格朗日乘子法 (Lagrange multiplier):构造 \(\mathcal L=w^\top\Sigma w-\lambda(\mathbf 1^\top w-1)\),对 \(w\) 求导令其为 0:

$$2\Sigma w-\lambda\mathbf 1=0\ \Rightarrow\ w=\tfrac{\lambda}{2}\Sigma^{-1}\mathbf 1 .$$

再用约束 \(\mathbf 1^\top w=1\) 解出 \(\lambda\),得到全局最小方差组合 (Global Minimum Variance, GMV):

$$w_{\text{GMV}}=\frac{\Sigma^{-1}\mathbf 1}{\mathbf 1^\top\Sigma^{-1}\mathbf 1}.$$

注意它完全不需要预期收益 \(\mu\)——这一点在 4.3 节会变得非常重要。

两资产手算:沿用前置知识里的例子,\(\sigma_1^2=0.04\),\(\sigma_2^2=0.01\),\(\sigma_{12}=0.006\)。两资产时 GMV 有简洁公式 \(w_1=\dfrac{\sigma_2^2-\sigma_{12}}{\sigma_1^2+\sigma_2^2-2\sigma_{12}}=\dfrac{0.004}{0.038}\approx10.5\%\),\(w_2\approx89.5\%\)。组合方差 \(\approx0.009579\),波动 \(\approx9.79\%\)——比波动 10% 的资产 2 单独持有还低。加入一个更危险的资产反而降低了风险,这就是相关性 \(\rho=0.3<1\) 带来的分散化。

推导 2:最大夏普(切点)组合

若存在无风险利率 \(r_f\),最大化 \(\dfrac{w^\top\mu-r_f}{\sqrt{w^\top\Sigma w}}\)。类似地可以推出

$$w_{\text{tan}}=\frac{\Sigma^{-1}(\mu-r_f\mathbf 1)}{\mathbf 1^\top\Sigma^{-1}(\mu-r_f\mathbf 1)}.$$

它叫切点组合 (tangency portfolio),因为从 \((0,r_f)\) 出发、与有效前沿相切的直线正好切在这个组合上。和第 2 章的“最大化 ICIR 加权”形式完全一样:\(\Sigma^{-1}\times\)“预期收益”。

import numpy as np
import cvxpy as cp

# 4 个虚构资产的“假设”年化预期收益、波动率和相关系数(教学用,非真实市场数据)
names = ["股票A", "股票B", "债券C", "商品D"]
mu = np.array([0.08, 0.10, 0.03, 0.06])
vol = np.array([0.20, 0.25, 0.05, 0.18])
corr = np.array([[1.0, 0.6, 0.1, 0.3],
                 [0.6, 1.0, 0.0, 0.3],
                 [0.1, 0.0, 1.0, 0.0],
                 [0.3, 0.3, 0.0, 1.0]])
Sigma = np.outer(vol, vol) * corr                  # 协方差 = σ_i σ_j ρ_ij
ones = np.ones(len(mu))
Si = np.linalg.inv(Sigma)                           # Σ^{-1}
rf = 0.02                                           # 无风险利率

# 1) 全局最小方差组合(允许做空):w = Σ^{-1}1 / (1ᵀΣ^{-1}1)
w_gmv = Si @ ones / (ones @ Si @ ones)
# 2) 切点组合 / 最大夏普(允许做空):w ∝ Σ^{-1}(μ − rf)
w_tan = Si @ (mu - rf); w_tan /= w_tan.sum()

def show(name, w):
    r, s = w @ mu, np.sqrt(w @ Sigma @ w)
    print(f"{name:10s} 权重=" + " ".join(f"{n}:{x:6.1%}" for n, x in zip(names, w)) +
          f" | 收益={r:.2%} 波动={s:.2%} 夏普={(r-rf)/s:.2f}")
show("最小方差", w_gmv)
show("最大夏普", w_tan)
show("等权", ones / 4)

# 3) 只做多 + 单资产不超过 50% 的最大夏普:用 cvxpy 求“给定收益下最小方差”,在收益网格上扫描
w = cp.Variable(4)
target = cp.Parameter()
prob = cp.Problem(cp.Minimize(cp.quad_form(w, Sigma)),
                  [cp.sum(w) == 1, w >= 0, w <= 0.5, mu @ w >= target])
best = None
for tr in np.linspace(0.03, 0.09, 61):              # 有效前沿:每个目标收益求一次
    target.value = tr
    prob.solve()
    if w.value is None:                              # 目标收益不可达时跳过
        continue
    wv = np.clip(w.value, 0, None); wv /= wv.sum()
    sr = (wv @ mu - rf) / np.sqrt(wv @ Sigma @ wv)
    if best is None or sr > best[0]:
        best = (sr, wv)
show("约束最大夏普", best[1])

4.3 估计误差:优化器是“误差放大器”

直觉

上一节的公式假设我们知道真实的 \(\mu\) 和 \(\Sigma\)。现实中它们都要从有限的历史数据中估计,而估计有误差。问题在于:优化器会系统性地偏爱那些“被高估了收益、被低估了风险”的资产——因为在它看来这些资产最“划算”。于是,样本内看起来最优的组合,样本外往往表现令人失望。这个现象常被称为“误差最大化”(Michaud 1989 的说法)。

  • 预期收益最难估:年化波动 20% 的资产,用 10 年数据估计年化均值,标准误约 \(20\%/\sqrt{10}\approx6.3\%\)——和均值本身一个量级。
  • 协方差相对好估,但维数高时也会出问题:\(N\) 个资产有 \(N(N+1)/2\) 个参数。50 只股票就是 1275 个参数;如果只有 60 个月的数据,样本协方差矩阵会严重病态 (ill-conditioned):最大与最小特征值之比(条件数 (condition number))非常大,求逆后的误差被放大。当 \(T<N\) 时它甚至不可逆。

Ledoit-Wolf 收缩

收缩估计 (shrinkage estimator)的思路:在“噪声大但无偏”的样本协方差 \(S\) 和“有偏但稳定”的结构化目标 \(F\)(例如对角阵、常数相关矩阵、单因子模型)之间取加权平均:

$$\hat\Sigma_{\text{shrink}}=\delta F+(1-\delta)S,\qquad 0\le\delta\le1 .$$

Ledoit 和 Wolf(2004)给出了使期望误差(Frobenius 范数下)最小的最优收缩强度 \(\delta^*\) 的估计公式,可以直接从数据算出,不需要调参。sklearn.covariance.LedoitWolf 使用的目标 \(F\) 是“对角线为平均方差的单位阵倍数”。这是典型的偏差-方差权衡 (bias-variance trade-off):引入一点偏差,换来方差的大幅下降。

import numpy as np
from sklearn.covariance import LedoitWolf

rng = np.random.default_rng(6)
N, T_train, T_test, trials = 50, 60, 250, 200   # 50 只资产,只有 60 个样本估计协方差
# 真实协方差:单因子结构(市场 β)+ 特质波动 —— 模拟设定
beta = rng.uniform(0.5, 1.5, N)
Sigma_true = np.outer(beta, beta) * 0.01**2 + np.diag(rng.uniform(0.01, 0.03, N)**2)
L = np.linalg.cholesky(Sigma_true)

def gmv(S):
    """全局最小方差权重(允许做空)。"""
    x = np.linalg.solve(S, np.ones(len(S)))
    return x / x.sum()

res = {"样本协方差": [], "Ledoit-Wolf": [], "真实协方差(理想)": []}
for _ in range(trials):
    X = rng.standard_normal((T_train, N)) @ L.T          # 训练期收益
    S_sample = np.cov(X, rowvar=False)
    S_lw = LedoitWolf().fit(X).covariance_               # 收缩估计
    for k, S in [("样本协方差", S_sample), ("Ledoit-Wolf", S_lw), ("真实协方差(理想)", Sigma_true)]:
        w = gmv(S)
        res[k].append(np.sqrt(w @ Sigma_true @ w) * np.sqrt(252))   # 组合真实的(样本外)年化波动

lw = LedoitWolf().fit(rng.standard_normal((T_train, N)) @ L.T)
print(f"一次拟合中 Ledoit-Wolf 收缩强度 δ={lw.shrinkage_:.2f}")
print(f"样本协方差条件数≈{np.linalg.cond(np.cov(rng.standard_normal((T_train, N)) @ L.T, rowvar=False)):.0f}")
for k, v in res.items():
    print(f"{k:14s} 最小方差组合的真实年化波动: 均值={np.mean(v):.2%}  最差={np.max(v):.2%}")

4.4 风险平价:让每个资产贡献同样的风险

直觉

等权组合“资金”平均,但“风险”并不平均:在 4 资产的例子里,股票 B 的波动是债券的 5 倍,等权组合的风险几乎全部来自股票。风险平价 (risk parity / equal risk contribution, ERC)的目标是让每个资产对组合总风险的贡献相等。

风险贡献的定义

组合波动 \(\sigma_p=\sqrt{w^\top\Sigma w}\) 是权重的一次齐次函数,由欧拉定理可以分解为

$$\sigma_p=\sum_i \underbrace{w_i\frac{\partial\sigma_p}{\partial w_i}}_{\text{RC}_i}=\sum_i\frac{w_i(\Sigma w)_i}{\sigma_p}.$$

其中 \((\Sigma w)_i\) 是向量 \(\Sigma w\) 的第 \(i\) 个元素,\(\partial\sigma_p/\partial w_i\) 叫边际风险贡献 (marginal risk contribution)。\(\text{RC}_i\) 是资产 \(i\) 的风险贡献 (risk contribution),所有 \(\text{RC}_i\) 加起来正好等于 \(\sigma_p\)。风险平价要求 \(\text{RC}_1=\text{RC}_2=\dots=\text{RC}_N\)。

手算特例:两个不相关的资产,波动 20% 和 5%。此时 \(\text{RC}_i\propto w_i^2\sigma_i^2\),相等要求 \(w_1\sigma_1=w_2\sigma_2\),即权重与波动成反比:\(w_1=\dfrac{1/0.20}{1/0.20+1/0.05}=20\%\),\(w_2=80\%\)。所以“反波动率加权”是风险平价在资产不相关时的特例;有相关性时需要数值求解。
📄 ch4_rp.py
import numpy as np
from scipy.optimize import minimize

vol = np.array([0.20, 0.25, 0.05, 0.18])            # 与 ch4_mv.py 同一组假设
corr = np.array([[1.0, 0.6, 0.1, 0.3], [0.6, 1.0, 0.0, 0.3],
                 [0.1, 0.0, 1.0, 0.0], [0.3, 0.3, 0.0, 1.0]])
Sigma = np.outer(vol, vol) * corr

def risk_contrib(w, S):
    """风险贡献 RC_i = w_i (Σw)_i / σ_p,各项之和等于组合波动 σ_p。"""
    sigma_p = np.sqrt(w @ S @ w)
    return w * (S @ w) / sigma_p

def rp_objective(w, S):
    rc = risk_contrib(w, S)
    return np.sum((rc - rc.mean())**2)               # 让每个资产的风险贡献尽量相等

n = len(vol)
res = minimize(rp_objective, np.ones(n) / n, args=(Sigma,), method="SLSQP",
               bounds=[(0, 1)] * n, constraints=[{"type": "eq", "fun": lambda w: w.sum() - 1}],
               options={"ftol": 1e-14})
w_rp = res.x
for name, w in [("等权", np.ones(n) / n), ("风险平价", w_rp), ("反波动率", (1/vol) / (1/vol).sum())]:

4.5 Black-Litterman:把观点和市场均衡结合起来

直觉

直接用历史均值当 \(\mu\) 太不稳定。Black 和 Litterman(1992)的想法是:先假设市场是对的——市场当前的权重 \(w_{\text{mkt}}\) 隐含了一组“均衡”预期收益;然后只在你有观点的地方,按观点的信心程度去偏离它。没有观点时,结果就是市场组合本身,不会出现极端权重。

第 1 步:反向优化求均衡收益

若所有人都按均值-方差持有组合,风险厌恶系数为 \(\delta\),则最优权重满足 \(w=(\delta\Sigma)^{-1}\mu\)。反过来,由市场权重可推出隐含收益:

$$\pi=\delta\,\Sigma\,w_{\text{mkt}} .$$

第 2 步:表达观点

符号含义本例
\(P\)(\(K\times N\))每行是一个观点涉及的资产组合观点 1:\((-1,1,0,0)\)“B 减 A”;观点 2:\((0,0,0,1)\)“D”
\(Q\)(长度 \(K\))每个观点的预期收益\(Q=(3\%,4\%)\)
\(\Omega\)(\(K\times K\))观点的不确定性(越大越没把握)常用 \(\operatorname{diag}(P\tau\Sigma P^\top)\)
\(\tau\)均衡收益本身的不确定性缩放,常取 0.01–0.1 量级0.05

第 3 步:后验收益(贝叶斯融合)

$$\mu_{\text{BL}}=\Big[(\tau\Sigma)^{-1}+P^\top\Omega^{-1}P\Big]^{-1}\Big[(\tau\Sigma)^{-1}\pi+P^\top\Omega^{-1}Q\Big]$$

读法:这是两个信息源的“精度加权平均”——精度就是方差的倒数。均衡 \(\pi\) 的精度是 \((\tau\Sigma)^{-1}\),观点 \(Q\) 的精度是 \(\Omega^{-1}\)。谁更确定,谁的话语权更大。

📄 ch4_bl.py
import numpy as np

names = ["股票A", "股票B", "债券C", "商品D"]
vol = np.array([0.20, 0.25, 0.05, 0.18])
corr = np.array([[1.0, 0.6, 0.1, 0.3], [0.6, 1.0, 0.0, 0.3],
                 [0.1, 0.0, 1.0, 0.0], [0.3, 0.3, 0.0, 1.0]])
Sigma = np.outer(vol, vol) * corr
w_mkt = np.array([0.35, 0.25, 0.30, 0.10])          # 假设的“市场/基准”权重
delta = 2.5                                          # 风险厌恶系数(常见取值 2~4,这里取 2.5)
tau = 0.05                                           # 先验不确定性缩放

# 1) 反推隐含均衡收益:π = δ Σ w_mkt(“市场持有这些权重,说明它隐含了这样的预期收益”)
pi = delta * Sigma @ w_mkt
# 2) 观点:① 股票B 比 股票A 年化多 3%;② 商品D 年化收益 4%
P = np.array([[-1, 1, 0, 0],
              [0, 0, 0, 1]], dtype=float)
Q = np.array([0.03, 0.04])
Omega = np.diag(np.diag(P @ (tau * Sigma) @ P.T))    # 观点不确定性(He-Litterman 常用设定)
# 3) 后验预期收益:
#    μ_BL = [(τΣ)^{-1} + Pᵀ Ω^{-1} P]^{-1} [(τΣ)^{-1} π + Pᵀ Ω^{-1} Q]
A = np.linalg.inv(tau * Sigma) + P.T @ np.linalg.inv(Omega) @ P
b = np.linalg.inv(tau * Sigma) @ pi + P.T @ np.linalg.inv(Omega) @ Q
mu_bl = np.linalg.solve(A, b)
# 4) 用后验收益做无约束均值-方差:w = (δΣ)^{-1} μ_BL
w_bl = np.linalg.solve(delta * Sigma, mu_bl)
for i, n in enumerate(names):
    print(f"{n}: 均衡收益 π={pi[i]:6.2%}  后验 μ_BL={mu_bl[i]:6.2%}  市场权重={w_mkt[i]:5.1%} → BL权重={w_bl[i]:6.1%}")
print(f"BL 权重合计={w_bl.sum():.3f}")
▶ 运行输出(模拟数据;不同版本库的数值可能有细微差异)
股票A: 均衡收益 π= 5.72%  后验 μ_BL= 5.73%  市场权重=35.0% → BL权重= 26.6%
股票B: 均衡收益 π= 6.87%  后验 μ_BL= 7.84%  市场权重=25.0% → BL权重= 33.4%
债券C: 均衡收益 π= 0.28%  后验 μ_BL= 0.25%  市场权重=30.0% → BL权重= 30.0%
商品D: 均衡收益 π= 2.60%  后验 μ_BL= 3.33%  市场权重=10.0% → BL权重= 18.3%

解读:均衡收益里股票 B(6.87%)已经比 A(5.72%)高 1.15%,我们的观点是“高 3%”,所以后验把 B 上调到 7.84%(没有完全达到 3% 的差距,因为观点并非百分之百确定);商品 D 的均衡收益只有 2.6%,观点认为是 4%,后验 3.33%。权重随之从 A 移向 B 和 D,债券几乎不变——没有观点的资产不会被乱动,这正是 BL 比直接优化稳健的地方。最后一行权重和为 1.083,是因为这里用的是无约束优化 \(w=(\delta\Sigma)^{-1}\mu\);实际使用时通常再加上满仓等约束。

4.6 HRP:不求逆矩阵的分层风险平价

直觉

López de Prado(2016)提出的分层风险平价 (Hierarchical Risk Parity, HRP)完全绕开了协方差矩阵求逆这个“误差放大器”。它的思路像整理衣柜:先把相似的资产归成一类(聚类),然后在类与类之间按风险分配资金,再逐层往下分。

三个步骤

  1. 树形聚类:用相关系数定义距离 \(d_{ij}=\sqrt{(1-\rho_{ij})/2}\)(\(\rho=1\) 时距离 0,\(\rho=-1\) 时距离 1),做层次聚类 (hierarchical clustering)。
  2. 准对角化:按聚类树的叶子顺序重排协方差矩阵,让相似资产相邻。
  3. 递归二分:把排好序的资产列表一分为二,两半各自计算“簇方差” \(V_L, V_R\),左半分到 \(\alpha=1-\dfrac{V_L}{V_L+V_R}\) 的权重、右半分到 \(1-\alpha\);对每一半递归,直到每组只剩一个资产。
📄 ch4_hrp.py
import numpy as np
import pandas as pd
from scipy.cluster.hierarchy import linkage, leaves_list
from scipy.spatial.distance import squareform

rng = np.random.default_rng(8)
# 模拟 8 个资产:两个“板块”(各 4 个),板块内相关高 —— 教学用
T, k = 500, 4
f1, f2 = rng.standard_normal(T), rng.standard_normal(T)
X = np.column_stack([0.8 * f1 + 0.6 * rng.standard_normal(T) for _ in range(k)] +
                    [0.7 * f2 + 0.7 * rng.standard_normal(T) for _ in range(k)])
X *= np.array([0.01, 0.012, 0.015, 0.02, 0.008, 0.01, 0.006, 0.009])   # 不同波动
ret = pd.DataFrame(X, columns=[f"A{i}" for i in range(8)])
cov, corr = ret.cov(), ret.corr()

# 第 1 步:树形聚类。距离 d_ij = sqrt((1 − ρ_ij)/2),相关越高距离越近
dist = np.sqrt((1 - corr) / 2)
link = linkage(squareform(dist.values, checks=False), method="single")
# 第 2 步:准对角化 —— 按聚类树的叶子顺序重排资产,相似资产排在一起
order = list(corr.index[leaves_list(link)])

def cluster_var(cov, items):
    """一个簇的方差:簇内用反方差权重组合后的方差。"""
    c = cov.loc[items, items]
    ivp = 1 / np.diag(c); ivp /= ivp.sum()
    return ivp @ c.values @ ivp

# 第 3 步:递归二分 —— 每次把列表劈成两半,按两半的风险反比分配权重
w = pd.Series(1.0, index=order)
clusters = [order]
while clusters:
    clusters = [c[j:k] for c in clusters for j, k in ((0, len(c)//2), (len(c)//2, len(c))) if len(c) > 1]
    for i in range(0, len(clusters), 2):
        left, right = clusters[i], clusters[i + 1]
        vl, vr = cluster_var(cov, left), cluster_var(cov, right)
        a = 1 - vl / (vl + vr)                       # 风险小的那半拿更多权重
        w[left] *= a
        w[right] *= 1 - a
print("聚类后的资产顺序:", order)
print("HRP 权重:", w.reindex(ret.columns).round(3).to_dict())
print("权重合计:", round(w.sum(), 6))
▶ 运行输出(模拟数据;不同版本库的数值可能有细微差异)
聚类后的资产顺序: ['A3', 'A1', 'A0', 'A2', 'A5', 'A7', 'A4', 'A6']
HRP 权重: {'A0': 0.102, 'A1': 0.067, 'A2': 0.039, 'A3': 0.025, 'A4': 0.174, 'A5': 0.108, 'A6': 0.353, 'A7': 0.132}
权重合计: 1.0

解读:聚类正确地把 A0–A3 和 A4–A7 两个“板块”分开了。由于第二个板块的资产整体波动更低,它们拿到了更多权重;板块内波动最低的 A6 权重最高(35%),波动最高的 A3 最低(2.5%)。整个过程只用到协方差的对角线和聚类结构,从不求逆,所以对估计误差不敏感。代价是它没有用到预期收益信息,也不保证任何意义上的“最优”。

4.7 带约束的优化:cvxpy 实战

为什么需要通用求解器

真实组合几乎总有约束:只做多、单票上限、行业偏离、换手上限、跟踪误差……加上这些后就没有解析解了。好消息是,大多数这类问题都是凸优化 (convex optimization)问题:目标函数是凸的(例如方差),约束构成凸集(线性约束、范数约束)。凸问题有两个优点:局部最优就是全局最优;有成熟的求解器。cvxpy 让你用接近数学公式的方式写问题,自动转换后交给求解器。

一个接近实战的问题

$$\max_w\ \alpha^\top w-\lambda\,(w-w_b)^\top\Sigma(w-w_b)-c\,\|w-w_0\|_1$$
项含义
\(\alpha^\top w\)模型给出的预期超额收益(来自第 2 章因子或第 5 章模型)
\((w-w_b)^\top\Sigma(w-w_b)\)相对基准 \(w_b\) 的跟踪误差 (tracking error)方差;\(w-w_b\) 叫主动权重
\(\|w-w_0\|_1=\sum_i|w_i-w_{0,i}|\)相对上期持仓 \(w_0\) 的双边换手,乘以成本 \(c\)
约束满仓、只做多、单票 ≤ 8%、换手 ≤ 40%、每个行业偏离基准 ≤ ±5%
📄 ch4_cvx.py
import numpy as np
import cvxpy as cp

rng = np.random.default_rng(9)
N = 30                                              # 30 只虚构股票
alpha = rng.normal(0, 0.02, N)                      # 模型给出的预期超额收益(模拟)
B = rng.normal(1, 0.3, (N, 1))                      # 单因子暴露
Sigma = B @ B.T * 0.15**2 + np.diag(rng.uniform(0.2, 0.4, N)**2)   # 年化协方差
industry = rng.integers(0, 3, N)                    # 3 个行业
w_bench = np.ones(N) / N                            # 基准:等权
w_prev = w_bench.copy()                             # 上期持仓
lam, tc = 5.0, 0.002                                # 风险厌恶、单边成本

w = cp.Variable(N)
active = w - w_bench                                # 主动权重
objective = cp.Maximize(alpha @ w
                        - lam * cp.quad_form(active, Sigma)        # 跟踪误差惩罚
                        - tc * cp.norm1(w - w_prev))               # 交易成本惩罚(换手)
cons = [cp.sum(w) == 1, w >= 0, w <= 0.08,                         # 满仓、只做多、个股上限 8%
        cp.norm1(w - w_prev) <= 0.4]                               # 单期双边换手 ≤ 40%
for g in range(3):                                                 # 行业偏离基准不超过 ±5%
    m = (industry == g).astype(float)
    cons += [cp.abs(m @ active) <= 0.05]
prob = cp.Problem(objective, cons)
prob.solve()
wv = w.value
te = np.sqrt((wv - w_bench) @ Sigma @ (wv - w_bench))
print(f"求解状态: {prob.status}")
print(f"持股数(权重>0.1%): {(wv > 1e-3).sum()}  最大权重: {wv.max():.2%}  换手: {np.abs(wv - w_prev).sum():.2%}")
print(f"预期超额收益: {alpha @ (wv - w_bench):.2%}  年化跟踪误差: {te:.2%}")
print("行业偏离:", [round(float(((industry == g) * (wv - w_bench)).sum()), 4) for g in range(3)])
▶ 运行输出(模拟数据;不同版本库的数值可能有细微差异)
求解状态: optimal
持股数(权重>0.1%): 29  最大权重: 8.00%  换手: 40.01%
预期超额收益: 1.15%  年化跟踪误差: 2.94%
行业偏离: [-0.0098, -0.0057, 0.0155]

解读:求解成功(optimal);单票上限 8% 和换手上限 40% 都是“紧”约束(刚好用满),说明如果放松它们,优化器还想更激进——这时要问自己:是信号真的强,还是 \(\alpha\) 估计过于自信?行业偏离都在 ±5% 以内。实际工作中,\(\alpha\) 的尺度(和 \(\lambda\) 的配合)需要校准,否则优化结果会过度集中。

4.8 方法对比:我该用哪一个

方法需要 \(\mu\)?需要 \(\Sigma^{-1}\)?优点缺点
等权否否最简单、最稳健,常是很难打败的基准忽略风险差异
最小方差否是不受收益估计误差影响集中于低波动资产
均值-方差 / 最大夏普是是理论最优对输入极其敏感
风险平价否否(需 \(\Sigma\))风险分散均衡低波动资产权重大,可能需要杠杆
Black-Litterman以观点形式是权重稳定、可融入主观或模型观点参数(\(\tau,\Omega,\delta\))需要设定
HRP否否对估计误差稳健,适合资产多、样本少无最优性保证
带约束优化(cvxpy)是隐含能表达真实世界约束和成本需要校准 \(\alpha\) 和风险模型

4.9 常见错误

  • ❌ 用历史平均收益直接作为 \(\mu\) 做无约束优化 → 极端权重,样本外很差。
  • ❌ 资产数接近或超过样本数时仍用样本协方差 → 矩阵病态甚至不可逆。✅ 收缩估计或因子模型。
  • ❌ 用 np.linalg.inv 显式求逆 → 数值不稳定。✅ 用 np.linalg.solve。
  • ❌ 用全样本估计 \(\Sigma\) 再回测历史组合 → 未来函数。✅ 每个调仓日只用当时之前的数据估计。
  • ❌ 忽略换手成本,每期都重新“从零优化” → 频繁大幅调仓。✅ 在目标函数中加入换手惩罚或约束。
  • ❌ 把“风险平价”和“等权”混为一谈。

4.10 本章小结

  • 组合方差 \(w^\top\Sigma w\);资产多时协方差项主导,分散化来自 \(\rho<1\)。
  • GMV:\(\Sigma^{-1}\mathbf1\) 归一化;切点组合:\(\Sigma^{-1}(\mu-r_f\mathbf1)\) 归一化。
  • 估计误差让优化器偏爱被高估的资产;Ledoit-Wolf 收缩 \(\delta F+(1-\delta)S\) 是简单有效的补救。
  • 风险平价:\(\text{RC}_i=w_i(\Sigma w)_i/\sigma_p\) 相等;不相关时退化为反波动率加权。
  • BL 用“精度加权”融合均衡收益与观点;HRP 用聚类 + 递归二分,完全不求逆。
  • 真实组合用凸优化(cvxpy)表达约束和成本。

5.2 特征工程

三条原则

  1. 只用当时可得的信息:每个特征在 \(t\) 时刻的值,只能依赖 \(t\) 时刻及以前的数据(rolling、pct_change 默认满足;shift(-1)、全样本标准化、bfill 不满足)。
  2. 尽量平稳:用收益、比率、z-score 代替价格水平。价格水平从 10 涨到 100,模型在训练期没见过 100,树模型就只能“外推”成训练集的边界值。
  3. 有经济含义:动量、波动、流动性、估值、情绪……每个特征最好能说出“为什么可能有用”。无意义特征越多,碰巧有效的假特征也越多。

常见特征族

族例子
价格动量 / 反转过去 5、20、60 日收益;价格相对均线的偏离
波动与风险滚动波动率、GARCH 波动预测(第 3 章)、下行波动、最大回撤
流动性换手率、成交额、Amihud 非流动性(|收益| ÷ 成交额)
基本面第 2 章的价值、质量因子(PIT!)
截面相对值每个特征在当日截面上的排名或 z-score(把时间序列问题转成截面问题)
进阶话题:López de Prado(2018)提出分数阶差分 (fractional differentiation),在“保持平稳”和“保留价格记忆”之间折中——一阶差分(收益率)平稳但丢掉了全部长期记忆,分数阶差分(例如 0.4 阶)可以保留一部分。

5.3 标签设计:三重障碍法

固定期限标签的问题

最简单的标签是“未来 \(h\) 天收益的符号”。它有两个问题:① 忽略了路径——一笔交易可能先跌 15% 触发止损,最后才涨回来,固定期限标签却记为“赚钱”;② 同样的阈值在高波动和低波动时期含义不同。

三重障碍法

三重障碍法 (triple-barrier method)(López de Prado, 2018)为每个样本设置三条“障碍”,标签由最先被碰到的那条决定:

障碍位置碰到后的标签
上障碍(止盈)\(P_{t_0}(1+k\,\sigma_{t_0})\)+1
下障碍(止损)\(P_{t_0}(1-k\,\sigma_{t_0})\)−1
垂直障碍(到期)\(t_0+h\)到期收益的符号(或 0)

其中 \(\sigma_{t_0}\) 是入场时用过去数据估计的波动率,\(k\) 是宽度倍数。这样障碍宽度自动适应波动环境。每个样本还记录了标签结束时间 \(t_1\)——它在下一节的交叉验证里至关重要。

例子:入场价 100 元,过去 20 日日波动 1.5%,\(k=2\),\(h=10\)。上障碍 103 元,下障碍 97 元。如果第 4 天收盘 97.2、第 5 天收盘 96.8,则第 5 天先碰到下障碍:标签 −1,\(t_1\)=第 5 天。如果 10 天内一直在 97–103 之间、第 10 天收盘 101,则标签 +1,\(t_1\)=第 10 天。

import numpy as np
import pandas as pd

def make_prices(n=2500, seed=11):
    """模拟日收盘价:带随机波动聚集的随机游走(没有可预测的规律)。"""
    rng = np.random.default_rng(seed)
    vol = np.empty(n); vol[0] = 0.015
    for t in range(1, n):                       # 让波动率慢慢变化,更像真实行情
        vol[t] = np.clip(vol[t-1] * np.exp(0.05 * rng.standard_normal()), 0.005, 0.05)
    ret = vol * rng.standard_normal(n)
    idx = pd.bdate_range("2015-01-01", periods=n)
    return pd.Series(100 * np.exp(np.cumsum(ret)), index=idx, name="close")

def triple_barrier(close, horizon=10, k=2.0, vol_win=20):
    """三重障碍标签:
       上障碍 = 入场价 × (1 + k·σ),下障碍 = 入场价 × (1 − k·σ),垂直障碍 = horizon 天后。
       先碰上障碍 → +1;先碰下障碍 → −1;都没碰到 → 用到期时收益的符号。
       返回标签和每个样本“标签结束时间” t1(后面做 purging 要用)。"""
    sigma = close.pct_change().rolling(vol_win).std()      # 用过去 20 天波动率设定障碍宽度
    labels, t1 = pd.Series(np.nan, index=close.index), pd.Series(pd.NaT, index=close.index)
    for i in range(vol_win, len(close) - horizon):
        p0, s = close.iloc[i], sigma.iloc[i]
        path = close.iloc[i + 1:i + 1 + horizon] / p0 - 1  # 未来 horizon 天的累计收益路径
        up = path[path >= k * s].index.min()               # 第一次触及上障碍的日期(没有则 NaT)
        dn = path[path <= -k * s].index.min()
        first = min([d for d in [up, dn] if pd.notna(d)], default=pd.NaT)
        if pd.isna(first):                                 # 两条水平障碍都没碰到
            labels.iloc[i], t1.iloc[i] = np.sign(path.iloc[-1]), path.index[-1]
        else:
            labels.iloc[i], t1.iloc[i] = (1 if first == up else -1), first
    return labels, t1

if __name__ == "__main__":
    close = make_prices()
    y, t1 = triple_barrier(close)
    ok = y.dropna()
    print("标签分布:", ok.value_counts().sort_index().to_dict())
    end_pos = close.index.get_indexer(t1.dropna())          # 标签结束日在序列中的位置
    start_pos = close.index.get_indexer(t1.dropna().index)   # 入场日的位置
    hold = end_pos - start_pos                                # 持有了多少个交易日
    print(f"平均持有 {hold.mean():.1f} 个交易日;  碰到垂直障碍(持满 10 天)的比例: {(hold == 10).mean():.0%}")
    print(ok.head(3).to_string())

5.4 交叉验证:为什么普通 K 折会骗你

直觉

K 折交叉验证 (K-fold cross-validation)把数据分成 K 份,轮流用 1 份测试、其余训练。默认实现常常打乱顺序。在金融数据上,打乱意味着:测试集里第 500 天的样本,它的“邻居”第 499 天和第 501 天就在训练集里。邻居的特征几乎一样(滚动窗口只差一天),标签也几乎一样(价格路径重叠)。模型只要“记住邻居”就能答对——这叫数据泄漏 (data leakage)。

Purging 与 Embargo

即使按时间顺序切块,块的边界上仍有泄漏。两种修补:

  • 清洗 (purging):从训练集中删除所有标签区间 \([t_0,t_1]\) 与测试集时间范围重叠的样本。形式化地,测试集覆盖 \([T_a,T_b]\),则训练样本 \(i\) 被删除当且仅当 \(t_{0,i}\le T_b\) 且 \(t_{1,i}\ge T_a\)。
  • 禁运期 (embargo):测试集之后紧邻的一小段样本也从训练集删除。原因是它们的特征(如 20 日滚动波动率)是用测试期内的数据计算的,与测试样本的标签相关。
例子:标签最长 10 天,测试块为第 100–149 天(\(t_1\) 最晚到第 159 天)。训练样本第 95 天的标签区间是 [95, 105],与测试区间重叠 → 删除;第 90 天的区间 [90, 100] 也碰到了第 100 天 → 删除;第 85 天的 [85, 95] 不重叠 → 保留。测试块之后,第 150–159 天的样本标签区间与测试区间重叠 → 删除;再往后取 1% 样本(约 24 天)作为禁运期 → 删除。

import pandas as pd
import lightgbm as lgb
from sklearn.model_selection import KFold

close = make_prices()

# ---- 特征工程:全部只用“当天及以前”的数据 ----

X = pd.DataFrame({
    "ret_5":   close.pct_change(5),                 # 过去 5 日收益
    "ret_20":  close.pct_change(20),                # 过去 20 日收益(动量)
    "vol_20":  r.rolling(20).std(),                 # 过去 20 日波动率

    "ma_gap":  close / close.rolling(60).mean() - 1,  # 价格偏离 60 日均线

def purged_kfold(index, t1, n_splits=5, embargo=0.01):
    """Purged K-Fold:按时间顺序切块;从训练集中删掉
       (a) 标签区间 [t, t1] 与测试集区间重叠的样本(purge),
       (b) 紧跟测试集之后一小段的样本(embargo)。"""
    n = len(index); emb = int(n * embargo)
    for test_idx in np.array_split(np.arange(n), n_splits):
        t0, t_end = index[test_idx[0]], t1.iloc[test_idx].max()   # 测试集覆盖的时间范围
        train_mask = np.ones(n, bool)
        train_mask[test_idx] = False
        overlap = (index <= t_end) & (t1.values >= t0)             # 标签区间与测试区间重叠
        train_mask &= ~overlap
        after = np.arange(test_idx[-1] + 1, min(n, test_idx[-1] + 1 + emb))
        train_mask[after] = False                                   # embargo:测试集之后再空出一段
        yield np.where(train_mask)[0], test_idx

def cv_score(splits):
    accs = []
    for tr, te in splits:
        model = lgb.LGBMClassifier(n_estimators=200, learning_rate=0.05, num_leaves=15,
                                   min_child_samples=20, subsample=0.8, subsample_freq=1,
                                   colsample_bytree=0.8, random_state=0, verbose=-1)
        model.fit(Xv.iloc[tr], yv.iloc[tr])
        accs.append(accuracy_score(yv.iloc[te], model.predict(Xv.iloc[te])))
    return np.mean(accs), np.std(accs)

naive = KFold(n_splits=5, shuffle=True, random_state=0).split(Xv)      # ❌ 打乱顺序的普通 K 折
plain = KFold(n_splits=5, shuffle=False).split(Xv)                     # 按时间切块,但不 purge
purged = purged_kfold(Xv.index, t1v, n_splits=5, embargo=0.01)         # ✅ purge + embargo
print("打乱的普通 KFold     准确率=%.3f ± %.3f" % cv_score(naive))
print("按时间切块(未purge) 准确率=%.3f ± %.3f" % cv_score(plain))
print("Purged + Embargo     准确率=%.3f ± %.3f" % cv_score(purged))
print("(数据是无规律的模拟随机游走,真实可达的准确率约等于“总猜多数类”的水平:%.3f)" % max(yv.mean(), 1 - yv.mean()))

5.5 树模型与 LightGBM

直觉

决策树 (decision tree)就是一串“如果……就……”的规则:例如“如果 20 日动量 > 5% 且波动率 < 2%,则预测上涨”。单棵树容易过拟合。梯度提升 (gradient boosting)的做法是:先训练一棵小树,看它哪里错了,再训练下一棵小树专门修正这些错误,如此反复,最终预测是所有树的加权和。LightGBM(Ke 等, 2017)是一个高效的梯度提升实现,对表格数据效果好、速度快,是量化中最常用的非线性模型之一。

控制过拟合的关键超参数

参数作用金融数据上的建议方向
num_leaves / max_depth每棵树的复杂度偏小(如 7–31),信噪比低时简单的树更稳
min_child_samples叶子节点最少样本数偏大,避免为少数样本建规则
learning_rate + n_estimators每棵树的步长与树的数量小步长 + 用时间顺序的验证集做早停
subsample、colsample_bytree每棵树随机抽样本/特征0.5–0.9,增加随机性、降低方差
reg_lambda、reg_alphaL2 / L1 正则适度加大
早停也会泄漏:早停 (early stopping)是在验证集表现不再提升时停止加树。如果用来早停的验证集就是最终报告成绩的测试集,等于在测试集上调参。正确做法是在训练集内部再按时间切出一段验证集。

5.6 特征重要性:别被“假重要”骗了

两类方法

  • split / gain 重要性(树内部统计,也叫 MDI (Mean Decrease Impurity)):某特征被用来分裂多少次、带来多少训练集上的增益。计算快,但有已知偏差:可切分点多的连续特征(包括纯噪声)更容易被选中,而且它只反映训练集。
  • 置换重要性 (permutation importance / MDA):在测试集上把某个特征的值随机打乱,看模型表现下降多少。下降多 = 模型真的依赖它、而且这种依赖在样本外成立。

import numpy as np
import pandas as pd
import lightgbm as lgb
from sklearn.inspection import permutation_importance
from sklearn.metrics import roc_auc_score

rng = np.random.default_rng(12)
n = 4000
# 模拟特征表:只有 f_signal1、f_signal2 真正有用,其余是纯噪声 —— 教学用
X = pd.DataFrame({
    "f_signal1": rng.standard_normal(n),
    "f_signal2": rng.standard_normal(n),
    "noise_cont": rng.standard_normal(n),            # 连续噪声:可切分点很多
    "noise_bin": rng.integers(0, 2, n).astype(float),  # 二值噪声:只有一个切分点
})
logit = 0.6 * X["f_signal1"] - 0.4 * X["f_signal2"]
y = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)

split = int(n * 0.7)                                  # 前 70% 训练、后 30% 测试(按顺序,不打乱)
Xtr, Xte, ytr, yte = X.iloc[:split], X.iloc[split:], y.iloc[:split], y.iloc[split:]
model = lgb.LGBMClassifier(n_estimators=150, learning_rate=0.05, num_leaves=7, min_child_samples=50,
                           random_state=0, verbose=-1).fit(Xtr, ytr)

split_imp = pd.Series(model.booster_.feature_importance("split"), index=X.columns)   # 被用来分裂的次数
gain_imp = pd.Series(model.booster_.feature_importance("gain"), index=X.columns)     # 分裂带来的总增益
perm = permutation_importance(model, Xte, yte, n_repeats=20, random_state=0, scoring="roc_auc")
out = pd.DataFrame({"split次数": split_imp, "gain占比": gain_imp / gain_imp.sum(),
                    "置换重要性(测试集AUC下降)": perm.importances_mean,
                    "置换重要性标准差": perm.importances_std})
print(out.round(4).to_string())
print(f"\n测试集 AUC = {roc_auc_score(yte, model.predict_proba(Xte)[:, 1]):.3f}")

解读:纯噪声 noise_cont 的 split 次数(270)几乎和真实信号 f_signal2(277)一样多,gain 也占了 14%——如果只看这两个指标,会以为它是重要特征。置换重要性则显示它的 AUC 下降(0.004)不到一个标准差(0.006),与 0 无法区分;而两个真实信号的下降都远大于各自的标准差。二值噪声 noise_bin 只有一个切分点,所以 split 次数少,看起来“不重要”——这恰好说明 split 计数反映的是“可切分性”,而不是“有用性”。

另一种常用方法是 SHAP 值 (SHapley Additive exPlanations),它把每个预测分解为各特征的贡献,适合解释单个预测。但它解释的是“模型怎么用特征”,同样不能证明这种用法在样本外有效。

5.7 从预测到策略

  1. 评估指标要贴近用途:准确率、AUC 衡量分类能力,但策略关心的是“预测分数高的股票是否真的涨得多”。把模型输出当作一个因子,用第 2 章的 RankIC、分层回测去评估,往往更有意义。
  2. 滚动训练:按时间滚动——用过去 \(N\) 年训练,预测下一个月,再往前滚。这模拟了实盘中“定期重新训练”的真实流程。
  3. 预测 → 权重:把预测分数转成第 4 章组合优化的 \(\alpha\) 输入,并加入换手和成本约束。
  4. 与简单基准对比:模型必须明显胜过“等权合成的线性因子”,否则复杂度不值得。

5.8 常见陷阱

  • ❌ 打乱顺序的交叉验证 / 随机划分训练测试集 → 严重高估(本章示例:73% vs 50%)。
  • ❌ 在整个数据集上做标准化、PCA、特征选择,然后才划分训练/测试 → 测试集信息泄漏进训练。✅ 所有预处理只在训练集上拟合。
  • ❌ 标签重叠却不 purge,样本之间不独立却当作独立 → 置信度虚高。
  • ❌ 用测试集早停、调参、挑特征 → 测试集变成了训练集的一部分。
  • ❌ 只看 split/gain 重要性下结论。
  • ❌ 用价格水平等非平稳特征 → 模型在新价格区间失效。
  • ❌ 反复修改模型直到测试集好看 → 这就是第 7 章的多重检验问题,最终需要一段“从未碰过”的保留数据。

5.9 本章小结

  • 金融 ML 的三大难点:低信噪比、样本不独立(标签重叠)、规律不稳定。
  • 特征只用过去信息、尽量平稳、有经济含义;三重障碍法按“先碰到哪条障碍”打标签,并记录结束时间 \(t_1\)。
  • 交叉验证必须按时间切块;用 purging 删除标签区间重叠的训练样本,用 embargo 删除测试集之后的一小段。
  • LightGBM 用小树、大叶子样本数、子采样、正则和时间顺序的早停来控制过拟合。
  • 用测试集上的置换重要性判断特征是否真正有用;split/gain 偏爱连续特征。

6.1 为什么需要事件驱动

向量化回测 (vectorized backtest)一次性对整列数据做运算(例如 pos.shift(1) * ret),快、简洁,适合研究阶段筛选想法。但它有几个天然的弱点:

  • 防未来函数靠自觉:整列数据都在内存里,写错一个 shift 就偷看了未来。
  • 难以表达路径依赖:订单被拒后怎么办?资金不足时买多少?止损在盘中哪个价格触发?这些都依赖“之前发生了什么”。
  • 和实盘代码是两套:研究时一套向量化代码,实盘时又要重写成逐笔处理的逻辑,两者不一致是常见的偏差来源。

事件驱动回测 (event-driven backtest)模拟真实世界的时间流:数据一根一根到来,每到一根就触发一串“事件”,各模块响应事件。它慢一些,但更真实,而且同一套策略代码可以直接接实盘数据源和交易接口。

6.2 架构总览

DataHandler—MarketEvent→Strategy—SignalEvent→Portfolio—OrderEvent→Execution—FillEvent→Portfolio
模块职责它不该做的事
DataHandler(数据)按时间顺序推送数据;只提供“截至现在”的历史让任何人看到未来数据
Strategy(策略)根据数据产生意图(目标仓位)关心资金、股数、成本
Portfolio(组合)记账(现金、持仓、净值);把意图变成具体订单(股数)决定成交价
Execution(撮合)模拟交易所/券商:决定能否成交、成交价、费用改变策略意图

模块之间只通过事件队列 (event queue)通信:谁产生事件就放进队列,主循环按先进先出顺序把事件分发给对应模块。这种解耦的好处是:换一个策略只改 Strategy;换成实盘只把 DataHandler 换成实时行情、Execution 换成券商接口。

6.4 DataHandler:从结构上杜绝未来函数

📄 ch6_engine.py(节选)
class DataHandler:
    """按日期逐根推送 K 线。关键:策略只能通过 history() 拿到“当前及以前”的数据。"""
    def __init__(self, bars: dict):                 # bars: {symbol: DataFrame[open, close, pre_close, volume]}
        self.bars = bars
        self.dates = sorted(set().union(*[df.index for df in bars.values()]))
        self.i = -1
    def update(self):
        self.i += 1
        return self.i < len(self.dates)             # 还有数据就返回 True
    @property
    def now(self):
        return self.dates[self.i]
    def history(self, symbol, field, n):
        df = self.bars[symbol]
        return df.loc[:self.now, field].iloc[-n:]   # 截至“现在”的最近 n 个值,杜绝未来函数
    def next_bar(self, symbol):
        """下一根 K 线(只给撮合模块用,用来模拟“次日开盘成交”)。"""
        df = self.bars[symbol]
        pos = df.index.searchsorted(self.now, side="right")
        return df.iloc[pos] if pos < len(df) else None
  • history() 用 df.loc[:self.now] 截断到“现在”,策略无论怎么写都拿不到未来数据。这比“记得 shift(1)”可靠得多。
  • next_bar() 是唯一能看到“下一根”的接口,只给撮合模块使用,用来模拟“今天收盘发信号、明天开盘成交”。这是一种受控的向前看:它代表的是“时间流逝到明天之后真实发生的成交”,而不是策略偷看。

6.5 Strategy:只表达意图

📄 ch6_engine.py(节选)
class MACrossStrategy:
    """双均线:短均线 > 长均线 → 目标仓位 = 1/股票数,否则 0。只在信号变化时发 SignalEvent。"""
    def __init__(self, data, events, symbols, fast=10, slow=40):
        self.data, self.events, self.symbols = data, events, symbols
        self.fast, self.slow = fast, slow
        self.state = {s: 0.0 for s in symbols}
    def on_market(self, ev):
        for s in self.symbols:
            closes = self.data.history(s, "close", self.slow)
            if len(closes) < self.slow:              # 数据不够计算长均线,先不动
                continue
            want = 1.0 / len(self.symbols) if closes.iloc[-self.fast:].mean() > closes.mean() else 0.0
            if want != self.state[s]:
                self.state[s] = want
                self.events.append(SignalEvent(ev.date, s, want))

和入门站的均线策略逻辑相同。两个细节:① 数据不足 slow 根时什么都不做(避免用不完整的窗口);② 只在目标变化时发信号,避免每天重复下单。

6.6 Portfolio:记账与下单数量

📄 ch6_engine.py(节选)
class Portfolio:
    """记账:现金、持仓、每日净值;把“目标仓位”翻译成“股数”(A 股按 100 股一手取整)。"""
    def __init__(self, data, events, cash=1_000_000):
        self.data, self.events = data, events
        self.cash, self.pos = cash, {}
        self.equity_curve, self.trades = [], []
    def total_value(self):
        mv = sum(q * self.data.history(s, "close", 1).iloc[-1] for s, q in self.pos.items())
        return self.cash + mv
    def on_signal(self, ev):
        price = self.data.history(ev.symbol, "close", 1).iloc[-1]       # 用今天收盘价估算股数
        target_qty = int(self.total_value() * ev.target / price // 100 * 100)
        qty = target_qty - self.pos.get(ev.symbol, 0)
        if qty != 0:
            self.events.append(OrderEvent(ev.date, ev.symbol, qty))
    def on_fill(self, ev):
        self.pos[ev.symbol] = self.pos.get(ev.symbol, 0) + ev.qty
        self.cash -= ev.qty * ev.price + ev.cost                         # 买入花钱、卖出收钱,成本总是扣
        self.trades.append(ev)
    def mark_to_market(self):
        self.equity_curve.append((self.data.now, self.total_value()))
  • 目标股数 = 总资产 × 目标仓位 ÷ 价格,再向下取整到 100 股(A 股买入以 100 股为一手,示意规则)。
  • 股数用当天收盘价估算,但成交在明天开盘——两者之间的差价意味着实际仓位不会精确等于目标,这是真实存在的误差。
  • on_fill 里现金的变化是 \(-(\text{股数}\times\text{成交价}+\text{费用})\):买入时股数为正,现金减少;卖出时股数为负,现金增加;费用总是减少现金。
  • 持仓以成交回报为准更新,而不是以“发出的订单”为准——订单可能被拒(下一节)。

6.7 Execution:成本模型与拒单

成本模型

设成交股数 \(q\)(买为正),参考价 \(P^{\text{open}}\),滑点 \(s\)(以比例计),佣金率 \(c\),最低佣金 \(m\),卖出印花税率 \(\tau\):

$$P^{\text{fill}}=P^{\text{open}}\,(1+s\cdot\operatorname{sign}(q)),\qquad N=|q|\,P^{\text{fill}}$$ $$\text{费用}=\max(N c,\ m)+\mathbb 1[q<0]\cdot N\tau$$

滑点 (slippage)总是对自己不利:买入价更高、卖出价更低。\(\mathbb 1[q<0]\) 是指示函数,卖出时为 1——A 股印花税只在卖出时收取(示意规则,以现行规定为准)。

手算一个来回(参数同代码默认值:滑点 5bp,佣金 0.025%,最低 5 元,卖出印花税 0.05%):
  1. 买入 10,000 股,开盘 10.00 元 → 成交价 10.005,金额 100,050 元;佣金 \(\max(25.01, 5)=25.01\) 元;滑点损失 \(10{,}000\times0.005=50\) 元。
  2. 卖出 10,000 股,开盘 10.00 元 → 成交价 9.995,金额 99,950 元;佣金 24.99 元;印花税 49.98 元;滑点损失 50 元。
  3. 一个来回总成本 ≈ 50 + 25.01 + 50 + 24.99 + 49.98 ≈ 200 元,约为本金的 0.2%。一年来回 30 次,就是约 6% 的收益被成本吃掉。
  4. 如果只买 100 股(1,000 元),佣金按最低 5 元收取,单边就是 0.5%——小资金频繁交易时,最低佣金是很重的负担。
📄 ch6_engine.py(节选)
class SimExecution:
    """模拟撮合:次日开盘价成交 + 滑点;佣金(有最低 5 元)+ 卖出印花税;涨跌停/停牌不能成交。
    费率为示意参数,请按你券商和交易所的实际规则修改。"""
    def __init__(self, data, events, slippage_bps=5, commission=0.00025, min_comm=5.0,
                 stamp_tax=0.0005, limit=0.10):
        self.data, self.events = data, events
        self.slip, self.comm, self.min_comm = slippage_bps / 1e4, commission, min_comm
        self.tax, self.limit = stamp_tax, limit
        self.rejected = 0
    def on_order(self, ev):
        bar = self.data.next_bar(ev.symbol)
        if bar is None or bar["volume"] <= 0:                           # 没有下一根或停牌
            self.rejected += 1; return
        up, down = bar["pre_close"] * (1 + self.limit), bar["pre_close"] * (1 - self.limit)
        if (ev.qty > 0 and bar["open"] >= up - 1e-9) or (ev.qty < 0 and bar["open"] <= down + 1e-9):
            self.rejected += 1; return                                  # 开盘涨停买不进 / 跌停卖不出
        px = bar["open"] * (1 + self.slip * np.sign(ev.qty))            # 滑点总是对自己不利
        notional = abs(ev.qty) * px
        cost = max(notional * self.comm, self.min_comm) + (notional * self.tax if ev.qty < 0 else 0)
        self.events.append(FillEvent(bar.name, ev.symbol, ev.qty, px, cost))

拒单逻辑:下一根 K 线停牌(成交量为 0)时任何方向都拒绝;开盘价已在涨停价时拒绝买入,已在跌停价时拒绝卖出。这是第 1 章“保守规则”的代码版本。被拒的订单在这个教学引擎里直接丢弃——更完善的做法是让策略在下一根 K 线重新评估(见 6.10)。

def run_backtest(bars, **exec_kw):
    events = deque()
    data = DataHandler(bars)
    strat = MACrossStrategy(data, events, list(bars))
    port = Portfolio(data, events)
    exe = SimExecution(data, events, **exec_kw)
    while data.update():                         # 外层循环:时间前进一天
        events.append(MarketEvent(data.now))
        while events:                            # 内层循环:把今天产生的事件处理完
            ev = events.popleft()
            if isinstance(ev, MarketEvent):  strat.on_market(ev)
            elif isinstance(ev, SignalEvent): port.on_signal(ev)
            elif isinstance(ev, OrderEvent):  exe.on_order(ev)
            elif isinstance(ev, FillEvent):   port.on_fill(ev)
        port.mark_to_market()                    # 收盘后记录净值
    eq = pd.Series(dict(port.equity_curve))
    return eq, port, exe

def summary(eq):
    r = eq.pct_change().dropna()
    dd = eq / eq.cummax() - 1
    return {"总收益": f"{eq.iloc[-1]/eq.iloc[0]-1:.2%}",
            "年化波动": f"{r.std()*np.sqrt(252):.2%}",
            "夏普": f"{r.mean()/r.std()*np.sqrt(252):.2f}",
            "最大回撤": f"{dd.min():.2%}"}

两层循环是事件驱动引擎的核心:外层推进时间,内层把当天产生的所有事件处理完。一个 MarketEvent 可能引出 SignalEvent → OrderEvent → FillEvent 一整串,它们都在同一个内层循环中依次处理。

def make_bars(seed, n=750, mu=0.0003, sigma=0.02, p_suspend=0.01, limit=0.10):
    """模拟日 K 线(open/close/pre_close/volume):涨跌幅截断在 ±10%,约 1% 的交易日停牌。
    纯教学用模拟数据,不对应任何真实股票。"""
    rng = np.random.default_rng(seed)
    idx = pd.bdate_range("2021-01-04", periods=n)
    rows, prev = [], 20.0
    for t in range(n):
        if rng.random() < p_suspend:                                   # 停牌:无成交,价格不变
            rows.append((prev, prev, prev, 0)); continue
        close = prev * np.exp(mu + sigma * rng.standard_normal())
        close = min(max(close, prev * (1 - limit)), prev * (1 + limit))   # 涨跌停截断
        opn = min(max(prev * (1 + 0.005 * rng.standard_normal()), prev * (1 - limit)), prev * (1 + limit))
        rows.append((opn, close, prev, int(rng.integers(100_000, 1_000_000))))
        prev = close
    return pd.DataFrame(rows, columns=["open", "close", "pre_close", "volume"], index=idx)

6.9 怎样验证引擎是对的

回测引擎本身的 bug 是最危险的,因为它会影响所有策略的结论。建议至少做这几类检查:

  1. 守恒检查:每天 现金 + Σ(持仓 × 收盘价) 应等于记录的净值;所有成交的现金流 + 费用之和应等于现金的变化。
  2. 零成本对照:关掉所有成本和整手限制,在不发生拒单的数据上,引擎结果应与一个正确的向量化实现(信号滞后、开盘成交)基本一致。
  3. 已知答案测试:构造一个“第 3 天买入、第 5 天卖出”的确定性策略和手算好的价格,检查每一笔成交价、费用、净值都与手算一致。
  4. 未来函数测试:把第 \(t\) 天之后的数据全部替换成随机数,第 \(t\) 天及以前的信号不应有任何变化。
  5. 边界情况:停牌、涨跌停、资金不足、最后一天发出的订单(没有下一根 K 线)。

缺少的功能为什么重要
限价单、部分成交、撤单市价单假设对低流动性股票不现实

6.11 常见错误

  • ❌ 用当天收盘价生成信号并以当天收盘价成交 → 隐含未来函数(收盘价出来时已经收盘了)。✅ 次日开盘成交,或明确假设“收盘前几分钟用近似收盘价成交”并加大滑点。
  • ❌ 持仓按订单而不是按成交更新 → 拒单后账实不符。
  • ❌ 忽略最低佣金和整手限制 → 小资金回测严重失真。
  • ❌ 滑点设为 0 → 高换手策略的结论可能完全相反(本章示例:5.26% → −1.98%)。
  • ❌ 不对引擎本身做测试 → 引擎 bug 污染所有研究结论。

7.2 收益归因:真 alpha 还是因子暴露

直觉

一个策略年化 14%,听起来不错。但如果市场同期涨了 10%,而策略的市场贝塔是 0.9,那么大部分收益只是“跟着市场走”。收益归因 (performance attribution)回答的就是“收益中有多少是可以被已知因素解释的”。

因子回归

$$r_{p,t}-r_{f,t}=\alpha+\beta_{\text{MKT}}\,\text{MKT}_t+\beta_{\text{SMB}}\,\text{SMB}_t+\beta_{\text{MOM}}\,\text{MOM}_t+\varepsilon_t$$
符号含义
\(r_{p,t}-r_{f,t}\)策略在第 \(t\) 期的超额收益
\(\text{MKT},\text{SMB},\text{MOM}\)市场超额收益、规模因子(小盘减大盘)、动量因子的收益序列(入门站第 5 章介绍的 Fama-French / Carhart 因子)
\(\beta\)策略对各因子的暴露 (exposure / loading)
\(\alpha\)截距:因子解释不了的平均收益——“真本事”的候选

两边取平均,就得到收益分解:\(\overline{r_p-r_f}=\hat\alpha+\sum_k\hat\beta_k\,\overline{F_k}\)。

import numpy as np
import statsmodels.api as sm

rng = np.random.default_rng(25)
T = 120                                                 # 10 年月度数据(全部为模拟)
mkt = 0.006 + 0.045 * rng.standard_normal(T)            # 市场超额收益
smb = 0.002 + 0.030 * rng.standard_normal(T)            # 规模因子(小盘 − 大盘)
mom = 0.004 + 0.035 * rng.standard_normal(T)            # 动量因子
# “策略”的真实构成:0.9 倍市场 + 0.6 倍规模 + 很小的真实 alpha(每月 0.1%)+ 特质噪声
strat = 0.001 + 0.9 * mkt + 0.6 * smb + 0.0 * mom + 0.015 * rng.standard_normal(T)

print(f"策略月均超额收益 = {strat.mean():.2%},年化 ≈ {strat.mean()*12:.1%}")
# 只对市场回归(CAPM):alpha 包含了规模暴露带来的收益
capm = sm.OLS(strat, sm.add_constant(mkt)).fit()
print(f"CAPM:      alpha = {capm.params[0]:.2%}/月 (t = {capm.tvalues[0]:.2f}),  β_mkt = {capm.params[1]:.2f}")
# 多因子回归:把规模、动量也放进来
X = sm.add_constant(np.column_stack([mkt, smb, mom]))
ff = sm.OLS(strat, X).fit()
a, b_mkt, b_smb, b_mom = ff.params
print(f"三因子:    alpha = {a:.2%}/月 (t = {ff.tvalues[0]:.2f}),  β_mkt = {b_mkt:.2f}, β_smb = {b_smb:.2f}, β_mom = {b_mom:.2f}")
print(f"R² = {ff.rsquared:.2f}  —— 收益的大部分可以被已知因子解释")
# 收益分解:平均收益 = alpha + Σ β × 因子平均收益
parts = {"alpha": a, "市场": b_mkt * mkt.mean(), "规模": b_smb * smb.mean(), "动量": b_mom * mom.mean()}
print("月均收益分解:", {k: f"{v:.3%}" for k, v in parts.items()}, " 合计:", f"{sum(parts.values()):.3%}")

7.3 参数敏感性与滚动前向

直觉

如果均线参数 (10, 200) 夏普 1.4,而 (10, 190) 和 (12, 200) 都只有 0.3,那么 (10, 200) 很可能是噪声中的一个尖峰,而不是真实规律。真实的效应通常是“一片高原”:附近参数都不错。

滚动前向分析

滚动前向分析 (walk-forward analysis)模拟“定期用过去数据重新选参数,然后用到未来”的真实流程:训练窗口选出最优参数 → 在紧随其后的测试窗口上评估 → 窗口整体向前滚动 → 把所有测试窗口的收益拼接起来,得到一条完全由样本外构成的收益曲线。

📄 ch7_walkforward.py
import numpy as np
import pandas as pd

rng = np.random.default_rng(24)
n = 252 * 8
# 模拟价格:前半段有趋势性(收益正自相关),后半段没有 —— 模拟“市场环境变化”
eps = rng.standard_normal(n) * 0.012
r = np.zeros(n)
for t in range(1, n):
    phi = 0.08 if t < n // 2 else 0.0
    r[t] = phi * r[t - 1] + eps[t]
close = pd.Series(100 * np.exp(np.cumsum(r)), index=pd.bdate_range("2016-01-01", periods=n))
ret = close.pct_change().fillna(0)

def strat_returns(fast, slow, cost=0.0005):
    """均线策略日收益(信号滞后一天,扣单边成本)。"""
    pos = (close.rolling(fast).mean() > close.rolling(slow).mean()).astype(float).shift(1).fillna(0)
    return pos * ret - pos.diff().abs().fillna(0) * cost

def sharpe(x):
    return x.mean() / x.std() * np.sqrt(252) if x.std() > 0 else 0.0

grid = [(f, s) for f in [5, 10, 20, 40] for s in [60, 120, 200] if f < s]
# ---- 参数敏感性:全样本上每组参数的夏普(注意:这一步只用来“看地形”,不用来挑参数)----
table = pd.Series({g: sharpe(strat_returns(*g)) for g in grid}).unstack()
print("全样本夏普(行=短均线,列=长均线):"); print(table.round(2).to_string())

# ---- 滚动前向:每次用过去 3 年选参数,在接下来 1 年上测试,然后整体往前滚 1 年 ----
all_r = {g: strat_returns(*g) for g in grid}
years = sorted(set(close.index.year))
oos = []
for k in range(3, len(years)):
    train = close.index.year.isin(years[k - 3:k]); test = close.index.year == years[k]
    best = max(grid, key=lambda g: sharpe(all_r[g][train]))
    oos.append(all_r[best][test])
    print(f"训练 {years[k-3]}-{years[k-1]} → 选中 {best},  样本内夏普={sharpe(all_r[best][train]):.2f},  "
          f"{years[k]} 年样本外夏普={sharpe(all_r[best][test]):.2f}")
print(f"拼接后的样本外夏普 = {sharpe(pd.concat(oos)):.2f}")

7.4 夏普比率本身的不确定性

标准误

夏普比率是从样本估计出来的,本身就有误差。在收益独立同分布(且近似正态)时,Lo(2002)给出了每期夏普 \(\widehat{SR}\) 的近似标准误:

$$\operatorname{SE}(\widehat{SR})\approx\sqrt{\frac{1+\tfrac12\widehat{SR}^2}{T}}$$

其中 \(T\) 是样本期数,\(\widehat{SR}\) 是每期(未年化)夏普。对日频数据,\(\widehat{SR}\) 很小,所以年化夏普的标准误近似为 \(\sqrt{1/\text{年数}}\)。

数值例子:3 年日频数据,年化夏普 1.0。标准误 ≈ \(\sqrt{1/3}\approx0.58\),95% 置信区间 ≈ \(1.0\pm1.96\times0.58=[-0.13,\ 2.13]\)——包含 0。也就是说,3 年夏普 1.0 在统计上并不能排除“真实夏普为 0”。要把标准误压到 0.25,需要约 16 年的数据。

Bootstrap 置信区间

当收益有肥尾、自相关时,上面的公式不够准确。Bootstrap(自助法)(bootstrap)用“从样本中有放回地重抽样”来模拟“如果历史重演一次会怎样”。为了保留收益的短期相关性,不逐日抽样,而是一次抽一整块连续的日子——块 bootstrap (block bootstrap)。

7.5 PSR 与 Deflated Sharpe Ratio

PSR:真实夏普超过某个门槛的概率

Bailey 和 López de Prado 提出的概率夏普比率 (Probabilistic Sharpe Ratio, PSR)把样本长度、偏度、峰度都考虑进来:

$$\text{PSR}(SR^*)=\Phi\!\left(\frac{(\widehat{SR}-SR^*)\sqrt{T-1}}{\sqrt{1-\hat\gamma_3\widehat{SR}+\frac{\hat\gamma_4-1}{4}\widehat{SR}^2}}\right)$$
符号含义
\(\widehat{SR}\)、\(SR^*\)样本夏普、比较的门槛(都用每期口径,不年化)
\(T\)样本期数
\(\hat\gamma_3\)偏度 (skewness):负偏(左尾长,偶尔大亏)会降低 PSR
\(\hat\gamma_4\)峰度 (kurtosis)(正态为 3):肥尾会降低 PSR
\(\Phi\)标准正态分布的累积分布函数

Deflated Sharpe:把“试了多少次”算进去

如果你试了 \(N\) 个策略,即使它们的真实夏普都是 0,挑出来的最大样本夏普也会明显大于 0。在各次尝试的夏普方差为 \(V\) 时,这个“纯靠运气的最大值”的期望近似为

$$E[\max\widehat{SR}]\approx\sqrt V\Big[(1-\gamma)\,\Phi^{-1}\!\big(1-\tfrac1N\big)+\gamma\,\Phi^{-1}\!\big(1-\tfrac1{Ne}\big)\Big]$$

其中 \(\gamma\approx0.5772\) 是欧拉-马歇罗尼常数,\(e\) 是自然常数。Deflated Sharpe Ratio (DSR)(Bailey & López de Prado, 2014)就是把这个期望值作为门槛的 PSR:\(\text{DSR}=\text{PSR}\big(E[\max\widehat{SR}]\big)\)。DSR 高(如 > 0.95)才说明“即使考虑到挑选,它仍大概率好于运气”。

📄 ch7_sharpe_stats.py
import numpy as np
from scipy import stats

def psr(returns, sr_benchmark=0.0):
    """Probabilistic Sharpe Ratio(Bailey & López de Prado):
    在考虑样本长度、偏度、峰度后,真实夏普 > sr_benchmark 的概率。夏普用“每期”口径(不年化)。"""
    r = np.asarray(returns)
    T = len(r)
    sr = r.mean() / r.std(ddof=1)
    g3 = stats.skew(r)                              # 偏度
    g4 = stats.kurtosis(r, fisher=False)            # 峰度(正态 = 3)
    denom = np.sqrt(1 - g3 * sr + (g4 - 1) / 4 * sr**2)
    return stats.norm.cdf((sr - sr_benchmark) * np.sqrt(T - 1) / denom)

def expected_max_sr(n_trials, var_sr):
    """在 n_trials 个“真实夏普都为 0”的策略中,样本夏普最大值的近似期望。"""
    g = 0.5772156649                                # 欧拉-马歇罗尼常数
    z1 = stats.norm.ppf(1 - 1 / n_trials)
    z2 = stats.norm.ppf(1 - 1 / (n_trials * np.e))
    return np.sqrt(var_sr) * ((1 - g) * z1 + g * z2)

def block_bootstrap_sharpe(r, block=20, n_boot=5000, seed=0):
    """移动块 bootstrap:整块(连续 block 天)地重抽样,保留收益的短期相关性。返回年化夏普的分布。"""
    rng = np.random.default_rng(seed)
    r = np.asarray(r); T = len(r)
    n_blocks = int(np.ceil(T / block))
    out = np.empty(n_boot)
    for b in range(n_boot):
        starts = rng.integers(0, T - block + 1, n_blocks)
        sample = np.concatenate([r[s:s + block] for s in starts])[:T]
        out[b] = sample.mean() / sample.std(ddof=1) * np.sqrt(252)
    return out

if __name__ == "__main__":

    sr_ann = r.mean() / r.std(ddof=1) * np.sqrt(252)

7.6 多重检验:试了 200 次之后

直觉

如果每次检验都用 5% 的显著性水平,那么检验 200 个毫无用处的策略,平均会有 10 个“显著”。这就是多重检验 (multiple testing)问题,也叫数据窥探 (data snooping)。

两种校正

方法控制什么规则特点
Bonferroni族错误率 (FWER):至少有一个假阳性的概率p 值 < α / N 才算显著非常保守
Benjamini-Hochberg(BH)错误发现率 (FDR):显著结果中假阳性的比例p 值从小到大排序,找最大的 \(k\) 使 \(p_{(k)}\le\alpha k/N\),前 \(k\) 个显著较宽松,适合“筛选候选”

order = np.argsort(p); k = np.arange(1, N + 1)
passed = p[order] <= 0.05 * k / N
n_bh = k[passed].max() if passed.any() else 0
print(f"BH(FDR=5%)显著的个数: {n_bh}")
# Deflated Sharpe:把“挑了 200 次”考虑进去
sr0 = expected_max_sr(N, sr.var(ddof=1))
print(f"200 次尝试下最大夏普的期望(年化)≈ {sr0*np.sqrt(252):.2f};  最好策略的 PSR(0)={psr(R[:, best]):.3f}  DSR={psr(R[:, best], sr0):.3f}")

7.7 PBO:回测过拟合的概率

直觉

你有 \(N\) 个候选配置(比如 50 组参数),按样本内表现挑出最好的那个。回测过拟合概率 (Probability of Backtest Overfitting, PBO)(Bailey, Borwein, López de Prado, Zhu, 2017)问的是:样本内最好的那个,在样本外排名落到中位数以下的概率有多大?如果挑选过程有价值,它在样本外也应该排名靠前。

CSCV 算法

  1. 把 \(T\times N\) 的收益矩阵按时间切成 \(S\) 块(如 16 块)。
  2. 枚举所有“选 \(S/2\) 块做样本内、其余做样本外”的组合,共 \(\binom{S}{S/2}\) 种(\(\binom{16}{8}=12870\))。这叫组合对称交叉验证 (Combinatorially Symmetric Cross-Validation, CSCV)。
  3. 每种组合下:找出样本内夏普最高的配置 \(n^*\);计算它在样本外的相对排名 \(\omega\in(0,1)\);记录 \(\lambda=\ln\frac{\omega}{1-\omega}\)。
  4. PBO = \(\lambda\le0\)(即样本外排名在中位数及以下)的组合所占比例。
📄 ch7_pbo.py
import numpy as np
from itertools import combinations

def pbo_cscv(R, S=16):
    """CSCV 估计回测过拟合概率 PBO(Bailey, Borwein, López de Prado, Zhu)。
    R: T×N 收益矩阵(N 个参数组合/策略)。把时间切成 S 块,枚举所有“一半块做样本内、另一半做样本外”的组合。"""
    T, N = R.shape
    blocks = np.array_split(np.arange(T), S)
    logits = []
    for is_idx in combinations(range(S), S // 2):
        oos_idx = [b for b in range(S) if b not in is_idx]
        IS = np.concatenate([blocks[b] for b in is_idx]); OOS = np.concatenate([blocks[b] for b in oos_idx])
        sr_is = R[IS].mean(0) / R[IS].std(0)
        sr_oos = R[OOS].mean(0) / R[OOS].std(0)
        n_star = np.argmax(sr_is)                               # 样本内最好的那个
        rank = (sr_oos < sr_oos[n_star]).sum() + 1              # 它在样本外的名次(1=最差)
        w = rank / (N + 1)                                      # 相对名次 ∈ (0,1)
        logits.append(np.log(w / (1 - w)))
    logits = np.array(logits)
    return (logits <= 0).mean(), len(logits)                    # 样本外跌到中位数以下的比例

rng = np.random.default_rng(23)
T, N = 1000, 50
noise = 0.01 * rng.standard_normal((T, N))                      # 情形 1:50 个纯噪声策略
pbo1, n_comb = pbo_cscv(noise)
skill = noise.copy(); skill[:, :5] += 0.0015                     # 情形 2:其中 5 个有真实正收益(模拟)
pbo2, _ = pbo_cscv(skill)
print(f"组合数 C(16,8) = {n_comb}")
print(f"纯噪声策略库:   PBO = {pbo1:.2f}")
print(f"含真实信号策略库: PBO = {pbo2:.2f}")
▶ 运行输出(模拟数据;不同版本库的数值可能有细微差异)
组合数 C(16,8) = 12870
纯噪声策略库:   PBO = 0.37
含真实信号策略库: PBO = 0.00

解读:50 个纯噪声策略时 PBO = 0.37——样本内最好的那个,超过三分之一的情况下样本外排名落到中位数以下(理论上纯噪声时 PBO 应在 0.5 附近,有限样本下会有波动);当其中 5 个策略含有真实的正收益时,PBO 降到 0——样本内最好的总是那几个真有信号的,它们在样本外也排名靠前。PBO 衡量的是“挑选流程”是否可信,而不是某一个策略。

7.9 常见错误

  • ❌ 只和“0”或“买入持有”比较 → 把因子暴露当成 alpha。
  • ❌ 用全样本敏感性表挑参数,再报告这组参数的全样本表现 → 双重使用数据。
  • ❌ 3 年回测夏普 1 就认为“统计显著”。
  • ❌ 不记录尝试次数 → 无法计算 DSR,也无法诚实评估。
  • ❌ 反复使用“保留集”→ 保留集变成了开发集。
  • ❌ 对 bootstrap 用逐日重抽样 → 破坏了收益自相关,置信区间偏窄。

7.10 本章小结

  • 收益归因:alpha 是否存在取决于对照因子;加入规模等因子后 alpha 可能大幅缩水。
  • 好参数应在“高原”上;滚动前向给出“选参数流程”的样本外评估。
  • 年化夏普标准误 ≈ \(\sqrt{1/\text{年数}}\);3 年夏普 1 的置信区间包含 0。
  • PSR 考虑样本长度、偏度、峰度;DSR 进一步把“尝试次数 N”折算进门槛。
  • Bonferroni 控制 FWER、BH 控制 FDR;PBO 用 CSCV 衡量“样本内最优在样本外是否仍好”。

8.1 为什么执行很重要

Perold(1988)提出了执行落差 (implementation shortfall, IS)的概念:“纸面组合”(决策时刻以当时价格瞬间、免费成交)与真实组合之间的收益差。它包括所有显性成本(佣金、税)和隐性成本(价差、冲击、价格在执行过程中的不利变动、没成交的机会成本)。对于高换手策略和资金规模较大的策略,执行成本常常决定了策略能否盈利、能承载多少资金。

8.2 限价订单簿

基本概念

  • 限价单 (limit order):指定价格,“不高于 X 买”或“不低于 X 卖”。不能立即成交的部分会挂在订单簿上等待,为市场提供流动性。
  • 市价单 (market order):不指定价格,以当前最优价立即成交,消耗流动性。(A 股的市价委托有多种类型和保护机制,以交易所规则为准。)
  • 限价订单簿 (limit order book, LOB):所有未成交限价单的集合,按价格排列。买方最高价叫买一(best bid),卖方最低价叫卖一(best ask)。
  • 价格-时间优先 (price-time priority):价格更优的单子先成交;同价位先到先成交。所以同价位排队的位置很重要。
  • 市场深度 (market depth):各价位上挂单的数量。深度越大,大单对价格的影响越小。
A 股常见的 Level-1 行情提供买卖各 5 档;开盘和收盘时段有集合竞价 (call auction),在一个时点集中撮合出单一价格,其余时间为连续竞价。具体时段和规则以交易所规定为准。

8.3 价差:最直接的流动性成本

定义

指标公式含义
中间价\(m=(P^{\text{bid}}+P^{\text{ask}})/2\)“公允价格”的常用近似
报价价差 (quoted spread)\(P^{\text{ask}}-P^{\text{bid}}\),相对值 \(/m\)立即买入再立即卖出的往返成本
有效价差 (effective spread)\(2\,|P^{\text{fill}}-m|/m\)按真实成交价衡量的成本(包含吃多档的影响)

用市价单买入,单边成本约为半个价差(从中间价到卖一)。如果订单量超过卖一的挂单量,就会继续“吃”卖二、卖三……成本随之上升。

例子:买一 10.00、卖一 10.02。中间价 10.01,报价价差 0.02 元 ≈ 20bp。市价买 200 股(卖一有 300 股):全部在 10.02 成交,相对中间价的成本 = (10.02−10.01)/10.01 ≈ 10bp,即半个价差。注意:对于 10 元的股票,最小报价单位 0.01 元本身就意味着至少约 10bp 的价差——低价股的相对价差往往更大。

# 一个极简的限价订单簿(Limit Order Book)—— 数字均为虚构示例
asks = [(10.02, 300), (10.03, 500), (10.04, 800), (10.05, 1200), (10.06, 2000)]   # 卖一 ~ 卖五 (价格, 股数)
bids = [(10.00, 400), (9.99, 600), (9.98, 900), (9.97, 1500), (9.96, 2500)]       # 买一 ~ 买五

best_ask, best_bid = asks[0][0], bids[0][0]
mid = (best_ask + best_bid) / 2                         # 中间价
spread = best_ask - best_bid                            # 绝对价差
print(f"买一={best_bid} 卖一={best_ask} 中间价={mid:.3f} 价差={spread:.2f} 元 = {spread/mid*1e4:.1f} bp")

def market_buy(book, qty):
    """市价买入 qty 股:从卖一开始逐档“吃掉”挂单,直到买够。返回成交均价和成交明细。"""
    left, cost, fills = qty, 0.0, []
    for price, size in book:
        take = min(left, size)
        fills.append((price, take)); cost += price * take; left -= take
        if left == 0:
            break
    if left > 0:
        raise ValueError("五档深度不够,剩余 %d 股无法成交" % left)
    return cost / qty, fills

for q in [200, 1000, 3000]:
    avg, fills = market_buy(asks, q)
    slip_bp = (avg - mid) / mid * 1e4                   # 相对中间价的成本(bp)
    print(f"市价买 {q:5d} 股: 成交均价={avg:.4f}  相对中间价成本={slip_bp:5.1f} bp  吃到 {len(fills)} 档")

# 订单簿不平衡度:买一量与卖一量的相对大小,常被用作极短期价格方向的特征
imb = (bids[0][1] - asks[0][1]) / (bids[0][1] + asks[0][1])

8.4 市场冲击

直觉

大单不只是吃掉现有挂单。持续买入会让卖方意识到“有大买家”,从而撤单、抬价;做市商也会因为库存风险而调整报价。市场冲击 (market impact)分两部分:

  • 临时冲击 (temporary impact):交易时价格被推开,交易结束后部分回落。它主要取决于交易速度。
  • 永久冲击 (permanent impact):交易传递了信息,价格永久移动。它主要取决于交易总量。

平方根定律

大量实证研究发现,元订单(一个大单拆成的所有子单)的平均冲击与订单量的平方根近似成正比:

$$I\approx Y\,\sigma_{\text{日}}\sqrt{\frac{Q}{V_{\text{日}}}}$$
符号含义
\(I\)冲击成本(相对价格的比例)
\(\sigma_{\text{日}}\)该股票日波动率
\(Q/V_{\text{日}}\)订单量占日成交量的比例
\(Y\)经验系数,需要用自己的成交数据校准
量级估算(取 \(Y=1\) 仅作示意):日波动 2%,订单占日成交量 5% → \(I\approx0.02\times\sqrt{0.05}\approx0.45\%=45\text{bp}\)。订单量翻 4 倍(到 20%),冲击只翻 2 倍(到约 89bp)。平方根意味着:规模越大,单位成本越高——这决定了一个策略的容量 (capacity)。

理论上,Kyle(1985)的模型用一个参数 \(\lambda\)(价格对订单流的敏感度,常称 Kyle's lambda)刻画永久冲击;Almgren 和 Chriss(2000)把执行问题表述为“冲击成本”与“等待期间价格波动风险”之间的权衡:下得快,冲击大但风险小;下得慢,冲击小但价格可能跑掉。

8.5 执行算法:TWAP、VWAP、POV、IS

算法规则优点缺点
TWAP (Time-Weighted Average Price)把母单在时间上均匀切分:每个区间下 \(Q/K\)最简单、可预测成交量小的时段参与率过高,冲击大
VWAP (Volume-Weighted Average Price)按预测的日内成交量分布切分:区间 \(k\) 下 \(Q\cdot v_k\)(\(v_k\) 为该区间成交量占比)参与率均匀,目标是贴近市场 VWAP依赖成交量预测;不关心价格走势
POV (Percentage of Volume)实时跟随市场成交量,保持固定参与率(如 10%)自动适应流动性完成时间不确定
IS / 到达价算法在冲击和风险之间优化(Almgren-Chriss 框架),通常前段下得更多直接以执行落差为目标需要冲击和风险模型

vwap = parent_qty * profile                                          # VWAP:按预测的成交量分布切分

def execute(schedule, eta=0.1):
    """临时冲击模型:每个区间的成交价 = 市场价 × (1 + η·σ·√(子单量/该区间成交量))。"""
    part = schedule / market_vol                                     # 参与率
    fill_px = price * (1 + eta * sigma_5m * 10 * np.sqrt(part))      # 系数为示意值
    avg = (fill_px * schedule).sum() / schedule.sum()
    return avg, part.max()

arrival = price[0]                                                   # 决策时(到达)价格
mkt_vwap = (price * market_vol).sum() / market_vol.sum()             # 全市场当日 VWAP
for name, sch in [("TWAP", twap), ("VWAP", vwap)]:
    avg, pmax = execute(sch)
    is_bp = (avg - arrival) / arrival * 1e4                          # 执行落差 Implementation Shortfall
    vs_vwap = (avg - mkt_vwap) / mkt_vwap * 1e4
    print(f"{name}: 成交均价={avg:.4f}  执行落差={is_bp:6.1f} bp  相对市场VWAP={vs_vwap:5.1f} bp  最大参与率={pmax:.1%}")

# ---- 2) 平方根冲击模型的“量级估算”:成本 ≈ Y · σ_日 · √(Q / V_日) ----
Y, sigma_d = 1.0, 0.02                                               # Y 为经验系数(需用自己的成交数据校准)
for q_frac in [0.01, 0.05, 0.20]:
    print(f"下单量=日成交量的 {q_frac:4.0%}: 估算冲击 ≈ {Y*sigma_d*np.sqrt(q_frac)*1e4:5.1f} bp")

  • 两种算法都要买 25 万股(日成交量的 5%)。VWAP 的最大参与率正好 5%(处处按量分配),TWAP 在成交量低的时段参与率升到 6.6%,所以冲击略大。
  • 执行落差约 15bp,其中大部分来自这一天模拟价格本身的上涨(相对市场 VWAP 只有 3–4bp)。执行落差同时包含“执行得好不好”和“运气”(价格走势),评估执行质量时要分开看。
  • 平方根模型给出的量级说明:同一个策略,资金规模扩大后成本会以非线性方式上升。

8.6 限价单还是市价单

市价单(吃单)限价单(挂单)
成交确定性高不确定,可能不成交
价格支付价差 + 冲击可能赚到价差
主要风险成本逆向选择与机会成本

逆向选择 (adverse selection):你的限价买单最容易在“价格要继续下跌”的时候被成交(因为知情的卖家愿意卖给你),而在“价格要上涨”的时候成交不了。所以挂单看似省了价差,但成交的那些往往是“不太好的”成交。机会成本 (opportunity cost):没成交的部分,价格跑掉了。对于信号衰减快的策略(第 2 章),机会成本可能比价差更贵。

8.7 交易成本分析(TCA)

交易成本分析 (Transaction Cost Analysis, TCA)事后评估执行质量。核心是选对基准:

基准衡量什么
决策价 / 到达价完整的执行落差,与策略最相关
区间 VWAP执行是否“随大流”;容易被自己的大单影响
收盘价适用于以收盘价为目标的策略
执行落差分解例子:决策时价格 10.00 元,计划买 10,000 股。实际买到 8,000 股,均价 10.05;剩下 2,000 股没买到,收盘 10.20;佣金 20 元。
  • 执行成本 = 8,000 × (10.05 − 10.00) = 400 元
  • 机会成本 = 2,000 × (10.20 − 10.00) = 400 元
  • 显性费用 = 20 元
  • 总执行落差 = 820 元,占纸面组合 10 万元的 0.82%(82bp)。
如果只看“成交均价相对 VWAP”,可能觉得执行不错,却忽略了一半的成本来自没成交的部分。

把 TCA 结果反馈给回测:用真实成交数据校准第 6 章引擎的滑点参数和本章的冲击系数 \(Y\),回测才会越来越接近实盘。

8.8 常见错误

  • ❌ 回测用固定很小的滑点,不随订单规模变化 → 高估策略容量。
  • ❌ 假设限价单在价格“碰到”时一定成交 → 忽略排队和逆向选择。
  • ❌ 只用 VWAP 评估执行 → 忽略机会成本和价格漂移。
  • ❌ 在成交量很小的时段(或低流动性股票上)下大单。
  • ❌ 用成交量预测时用到了当天的真实成交量(未来函数)。

8.9 本章小结

  • 订单簿按价格-时间优先撮合;市价单消耗流动性,限价单提供流动性。
  • 单边吃单成本 ≈ 半个价差;订单越大、吃的档位越多,成本非线性上升。
  • 平方根冲击:\(I\approx Y\sigma\sqrt{Q/V}\),决定策略容量。
  • TWAP 按时间切、VWAP 按成交量切、POV 跟随成交量、IS 权衡冲击与风险。
  • 执行落差 = 执行成本 + 机会成本 + 显性费用;用 TCA 校准回测参数。

9.3 风控系统:事前、事中、事后

三层防线

层次时机例子
事前 (pre-trade)订单发出前单笔金额上限、价格偏离上限(防“乌龙指”)、单票仓位上限、黑名单、整手检查、每日委托笔数上限
事中 (intraday)交易过程中当日亏损阈值触发停止开仓;撤单率、成交率异常;总开关(kill switch)
事后 (post-trade)收盘后 / 定期对账;回撤、风险暴露、因子暴露报告;实盘与回测偏差分析

总开关 (kill switch)是最重要也最容易被忽视的功能:一个按钮(或一条自动规则)就能立刻停止所有新订单、撤销所有挂单。程序失控时,几分钟就可能造成巨大损失。

from dataclasses import dataclass, field
import numpy as np

@dataclass
class RiskLimits:                       # 风控参数:全部是示意值,请根据自己的资金规模和策略设定
    max_order_value: float = 200_000    # 单笔委托金额上限(元)
    max_position_pct: float = 0.10      # 单只股票持仓占总资产上限
    max_daily_orders: int = 200         # 每日委托笔数上限(防止程序死循环狂发单)
    max_price_dev: float = 0.03         # 委托价偏离最新价上限(防“乌龙指”)
    daily_loss_stop: float = 0.03       # 当日亏损达到 3% 停止开新仓
    blacklist: set = field(default_factory=lambda: {"ST_XYZ"})

class PreTradeRisk:
    """事前风控:每一笔委托发出前都必须通过全部检查,任何一条不满足就拒绝并记录原因。"""
    def __init__(self, limits: RiskLimits, equity: float):
        self.lim, self.equity, self.start_equity = limits, equity, equity
        self.orders_today, self.positions = 0, {}
        self.kill_switch = False                                     # 人工或自动触发的“总开关”

    def check(self, symbol, qty, price, last_price):
        L = self.lim
        value = abs(qty) * price
        new_pos_value = (self.positions.get(symbol, 0) + qty) * last_price
        rules = [
            (self.kill_switch, "总开关已关闭"),
            (symbol in L.blacklist, "标的在黑名单"),
            (qty % 100 != 0 and qty > 0, "买入数量不是 100 股整数倍"),
            (value > L.max_order_value, f"单笔金额 {value:,.0f} 超过上限"),
            (abs(price / last_price - 1) > L.max_price_dev, "委托价偏离最新价过大"),
            (new_pos_value > L.max_position_pct * self.equity, "成交后单票仓位超限"),
            (self.orders_today >= L.max_daily_orders, "当日委托笔数已达上限"),
            (qty > 0 and self.equity / self.start_equity - 1 <= -L.daily_loss_stop, "当日亏损触发止损,禁止开仓"),
        ]
        for hit, reason in rules:
            if hit:
                return False, reason
        self.orders_today += 1
        return True, "通过"

    def on_fill(self, symbol, qty):
        """成交回报到达后更新持仓 —— 持仓以成交为准,而不是以“发出的委托”为准。"""
        self.positions[symbol] = self.positions.get(symbol, 0) + qty

risk = PreTradeRisk(RiskLimits(), equity=1_000_000)
tests = [("X0001", 5000, 10.00, 10.00), ("X0001", 30000, 10.00, 10.00), ("X0002", 1000, 10.80, 10.00),

9.6 合规提示

以下仅为学习提示,不构成法律意见。规则会更新,请以中国证监会、交易所、你所在券商的最新规定和要求为准。
  • 程序化交易监管:中国证监会于 2024 年发布了《证券市场程序化交易管理规定(试行)》,沪深北交易所也发布了相应的实施细则,对程序化交易的报告、高频交易的额外要求、异常交易监控等作出规定。使用程序自动下单前,应向券商了解报告义务和接入要求。
  • 交易接口:通过券商提供的正规接口接入;不要使用来路不明的“破解”接口或第三方转发服务,既有合规风险也有资金安全风险。
  • 异常交易行为:频繁申报并撤单、大量申报影响价格、在涨跌停价位大量挂撤单等,可能被交易所认定为异常交易。风控里的“撤单率上限”“每日委托笔数上限”也有这方面的作用。
  • 账户与资金:不要出借、借用证券账户;为他人管理资金、收费荐股等涉及持牌要求。
  • 数据使用:注意行情和数据的授权范围,商业数据通常不能随意再分发。

9.8 常见错误

  • ❌ 跳过模拟盘直接实盘 → 系统 bug 用真金白银去发现。
  • ❌ 本地持仓记录与券商不对账 → 误差累积,风控基于错误状态。
  • ❌ 没有总开关、没有每日委托上限 → 程序失控时无法止损。
  • ❌ 亏损时临时放宽风控参数。
  • ❌ 实盘与回测偏差扩大却不排查,只是“再等等看”。
  • ❌ 不了解程序化交易的报告和异常交易规定。
